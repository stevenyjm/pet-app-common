## 1. 概述

任务可视化调度平台提供 2 个模块的管理端 API：

| 模块 | 路径前缀 | 权限前缀 |
|------|---------|---------|
| 后端定时任务管理 | `/api/v1/admin/cron-tasks` | `cron_task:` |
| 消息广播定时任务管理 | `/api/v1/admin/broadcast-schedules` | `broadcast_schedule:` |

**统一响应格式**：

```json
{ "code": 0, "message": "success", "data": {} }
```

**鉴权**：所有接口需 `Authorization: Bearer <admin_access_token>` + 对应权限码。

**时间字段**：所有时间字段为 ISO 8601 格式北京时间（`+08:00`）。

## 2. 后端定时任务管理 API

### 2.1 GET /api/v1/admin/cron-tasks

列举所有定时任务清单（静态清单 + 最近一次执行记录 + 下次预计执行时间）。

**请求参数**

| 参数 | 类型 | 必填 | 来源 | 说明 |
|------|------|------|------|------|
| Authorization | string | 是 | header | Bearer token |
| keyword | string | 否 | query | 任务编码/名称模糊搜索（前端过滤可选） |

**权限**：`cron_task:view`

**成功响应**（code: 0）

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "list": [
      {
        "task_code": "cron:order-expiry",
        "task_name": "订单过期释放",
        "description": "扫描过期订单并释放预占库存",
        "schedule_cron": "*/5 * * * *",
        "schedule_type": "internal_node_cron",
        "enabled": true,
        "last_execution": {
          "log_id": 123,
          "trigger_type": 0,
          "start_time": "2026-08-22T08:25:00+08:00",
          "end_time": "2026-08-22T08:25:02+08:00",
          "duration_ms": 2034,
          "status": 1,
          "result_summary": { "scanned": 10, "processed": 3 }
        },
        "next_scheduled_at": "2026-08-22T08:30:00+08:00"
      }
    ],
    "total": 3
  }
}
```

**响应字段说明**

| 字段 | 类型 | 说明 |
|------|------|------|
| list | array | 任务列表 |
| list[].task_code | string | 任务编码（如 `cron:order-expiry`） |
| list[].task_name | string | 任务名称 |
| list[].description | string | 任务描述 |
| list[].schedule_cron | string | cron 表达式（部署约定） |
| list[].schedule_type | string | 调度方式：`internal_node_cron`（脚本内 node-cron）/ `external`（外部调度一次性脚本） |
| list[].enabled | boolean | 是否启用 |
| list[].last_execution | object\|null | 最近一次执行记录（取 `cron_task_execution_log` 最新一条；无记录时为 null） |
| list[].last_execution.log_id | number | 日志主键 |
| list[].last_execution.trigger_type | number | 触发类型：0-定时调度；1-管理员手动触发 |
| list[].last_execution.start_time | string | 执行开始时间（ISO 8601） |
| list[].last_execution.end_time | string\|null | 执行结束时间 |
| list[].last_execution.duration_ms | number\|null | 执行耗时（毫秒） |
| list[].last_execution.status | number | 执行状态：0-运行中；1-成功；2-失败；3-超时 |
| list[].last_execution.result_summary | object\|null | 执行结果摘要 |
| list[].next_scheduled_at | string\|null | 下次预计执行时间（cron-parser 计算；`external` 类型为部署约定展示） |

**可能的错误码**

| code | 说明 |
|------|------|
| 40101 | 未登录 / Token 失效 |
| 40301 | 无 `cron_task:view` 权限 |
| 50001 | 服务器内部错误 |

### 2.3 POST /api/v1/admin/cron-tasks/:task_code/trigger

手动触发一次任务执行（同步等待返回结果，60s 超时）。

**请求参数**

| 参数 | 类型 | 必填 | 来源 | 说明 |
|------|------|------|------|------|
| Authorization | string | 是 | header | Bearer token |
| task_code | string | 是 | path | 任务编码（URL 编码） |

**权限**：`cron_task:trigger`

**成功响应**（code: 0，任务在 60s 内完成）

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "task_code": "cron:order-expiry",
    "result": { "scanned": 10, "processed": 3 }
  }
}
```

**超时响应**（code: 0，任务超过 60s 未完成，后台继续执行）

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "task_code": "cron:order-expiry",
    "status": "timeout",
    "message": "任务已触发，结果稍后查看历史"
  }
}
```

**响应字段说明**

| 字段 | 类型 | 说明 |
|------|------|------|
| task_code | string | 任务编码 |
| result | object\|null | 执行结果摘要（超时响应无此字段） |
| status | string | 仅超时响应包含，值为 `timeout` |
| message | string | 仅超时响应包含，提示用户稍后查看历史 |

**可能的错误码**

| code | 说明 |
|------|------|
| 40001 | 参数错误（task_code 为空） |
| 40101 | 未登录 / Token 失效 |
| 40301 | 无 `cron_task:trigger` 权限 |
| 40436 | 任务不存在或已禁用（`CRON_TASK_NOT_FOUND`） |
| 50001 | 任务执行失败（错误信息见 message） |

**审计日志**：写入 `admin_audit_log`，`action='cron_task_trigger'`，`resource_type='cron_task'`，`resource_id=task_code`，`detail={ trigger_type:'manual', result_summary }`。

### 3.2 POST /api/v1/admin/broadcast-schedules

新增广播调度（选 preset + scheduled_at）。

**请求参数**

| 参数 | 类型 | 必填 | 来源 | 说明 |
|------|------|------|------|------|
| Authorization | string | 是 | header | Bearer token |
| preset_message_id | number | 是 | body | 预设广播消息 ID（仅 status=1 启用项可选） |
| scheduled_at | string | 是 | body | 计划发送时间（ISO 8601，必须晚于当前时间） |

**请求体示例**

```json
{
  "preset_message_id": 12,
  "scheduled_at": "2026-08-23T20:00:00+08:00"
}
```

**权限**：`broadcast_schedule:manage`

**成功响应**（code: 0）

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "schedule_id": 1,
    "preset_message_id": 12,
    "scheduled_at": "2026-08-23T20:00:00+08:00",
    "broadcast_status": 0,
    "created_at": "2026-08-22T10:00:00+08:00"
  }
}
```

**可能的错误码**

| code | 说明 |
|------|------|
| 40001 | 参数错误（preset_message_id 为空 / scheduled_at 为空 / scheduled_at 不晚于当前时间） |
| 40101 | 未登录 / Token 失效 |
| 40301 | 无 `broadcast_schedule:manage` 权限 |
| 40433 | 预设广播不存在或已禁用（`PRESET_BROADCAST_NOT_FOUND`） |
| 42228 | 同一 preset 同一时刻已存在待发送调度（`BROADCAST_SCHEDULE_DUPLICATE`） |
| 50001 | 服务器内部错误 |

**审计日志**：写入 `admin_audit_log`，`action='broadcast_schedule_create'`，`resource_type='broadcast_schedule'`，`resource_id=schedule_id`，`detail={ preset_message_id, scheduled_at }`。
