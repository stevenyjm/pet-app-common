## 2. 预设广播消息 `/admin/preset-broadcast`

### 2.1 GET `/admin/preset-broadcast`

预设广播列表。

**请求参数（query）**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| status | number | 否 | 1-启用；0-禁用；不传=全部 |
| page | number | 否 | 默认 1 |
| page_size | number | 否 | 默认 20 |

**成功响应**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "list": [
      {
        "id": 1,
        "title": "周末满减活动",
        "content": "本周末全场满 99 减 10",
        "target_type": "all",
        "target_value": null,
        "sort_order": 0,
        "status": 1,
        "created_at": "2026-08-21T10:00:00+08:00",
        "updated_at": "2026-08-21T10:00:00+08:00"
      }
    ],
    "total": 1,
    "page": 1,
    "page_size": 20
  }
}
```

### 2.2 POST `/admin/preset-broadcast`

新增预设广播。非查询操作 → 计入 `admin_audit_log`（`action=preset_broadcast_create`，`resource_type=preset_broadcast`）。

**请求体**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| title | string | 是 | 标题，≤128 字 |
| content | string | 是 | 内容，≤500 字 |
| target_type | string | 否 | `all`（默认）或 `users` |
| target_value | string | 否 | `target_type=users` 时为逗号分隔 user_id |
| sort_order | number | 否 | 默认 0 |
| status | number | 否 | 默认 1 |

**可能的错误码**

| code | 说明 |
|------|------|
| 40001 | 标题/内容为空或超长 |
| 40433 | 预设广播不存在（编辑/删除时） |

### 2.3 PUT `/admin/preset-broadcast/:id`

编辑。非查询操作 → 计入审计（`action=preset_broadcast_update`）。

### 2.4 DELETE `/admin/preset-broadcast/:id`

软删除（`UPDATE is_deleted=1`）。非查询操作 → 计入审计（`action=preset_broadcast_delete`）。

## 3. 营养因子矩阵 `/admin/nutrition-matrix`

### 3.1 因子（行）

| 方法 | 路径 | 说明 | 审计 action |
|------|------|------|-----------|
| GET | `/admin/nutrition-matrix/factors` | 因子列表 | — |
| POST | `/admin/nutrition-matrix/factors` | 新增因子 | `nutrition_factor_create` |
| PUT | `/admin/nutrition-matrix/factors/:id` | 编辑因子 | `nutrition_factor_update` |
| DELETE | `/admin/nutrition-matrix/factors/:id` | 软删因子（联动软删 value） | `nutrition_factor_delete` |

**因子字段**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | number | 主键 |
| factor_code | string | 编码 snake_case，唯一(含 is_deleted) |
| factor_name | string | 名称，≤64 字 |
| unit | string | 单位，默认 `%` |
| sort_order | number | 排序 |
| status | number | 1-启用；0-禁用 |
| created_at / updated_at | string | 时间 |

### 3.2 维度（列）

| 方法 | 路径 | 说明 | 审计 action |
|------|------|------|-----------|
| GET | `/admin/nutrition-matrix/dimensions` | 维度列表 | — |
| POST | `/admin/nutrition-matrix/dimensions` | 新增维度 | `nutrition_dimension_create` |
| PUT | `/admin/nutrition-matrix/dimensions/:id` | 编辑维度 | `nutrition_dimension_update` |
| DELETE | `/admin/nutrition-matrix/dimensions/:id` | 软删维度（联动软删 value） | `nutrition_dimension_delete` |

**维度字段**：`id`/`dim_code`/`dim_name`/`sort_order`/`status` + 时间字段。

### 3.3 矩阵值

#### GET `/admin/nutrition-matrix`

返回整张矩阵（因子×维度×值）。

```json
{
  "code": 0,
  "data": {
    "factors": [{ "id": 1, "factor_code": "crude_protein", "factor_name": "蛋白质占比", "unit": "%", "sort_order": 0, "status": 1 }],
    "dimensions": [{ "id": 1, "dim_code": "infancy", "dim_name": "幼年期", "sort_order": 0, "status": 1 }],
    "values": [
      { "id": 10, "factor_id": 1, "dimension_id": 1, "factor_value": 26.00 }
    ]
  }
}
```

#### PUT `/admin/nutrition-matrix/values`

批量 upsert 单元格值。非查询操作 → 计入审计（`action=nutrition_value_update`）。

**请求体**

```json
{
  "values": [
    { "factor_id": 1, "dimension_id": 1, "factor_value": 26.00 },
    { "factor_id": 1, "dimension_id": 2, "factor_value": 30.50 }
  ]
}
```

## 4. 营养素来源校验（硬化）

### 4.1 适用接口

| 接口 | 方法 | 路径 | 校验点 |
|------|------|------|--------|
| SKU 营养信息保存 | POST/PUT | `/admin/products/:product_id/skus`、`/admin/products/:product_id/skus/:sku_id` | `nutrition_json.extra[].code` 命中营养配置表启用且未删除项 |
| C 端餐食记录 | PUT | `/pets/:pet_id/daily-records/:date`（含餐次 items） | `items[].nutrition_json.extra[].code` 同上 |

### 4.2 错误码

| code | 常量 | 说明 |
|------|------|------|
| 40057 | `NUTRITION_EXTRA_INVALID_CODE` | 额外营养素 code 不在营养配置表启用项中 |

**响应示例**

```json
{ "code": 40057, "message": "额外营养素 code 无效：xxx，须为营养配置表已有项", "data": null }
```

## 9. 小程序工作台联动（WB · L-RG-62）

> 信息注册台软删商品/商品分类/资讯时，若该项目已在「小程序工作台」发布版本中，需二次确认后同步下架并禁止再次发布。
> 关联需求：`pet-app-common/docs/requirements/2026-08-21-需求-小程序工作台.md` §5.8

### 9.1 DELETE `/admin/products/:id`（商品软删 · 工作台联动）

**请求参数（query）**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| force_workbench_offline | string | 否 | `true` 或 `1`：确认同步下架工作台已发布商品并加入禁止列表；不传则触发二次确认 |

**联动逻辑**

1. 若商品在工作台 `workbench_draft`（`module_type='product_publish'` 且 `publish_status=1`）中已发布，且未传 `force_workbench_offline`：
   - 返回 `409` + `code=40901`（`PRODUCT_WORKBENCH_PUBLISHED`），提示前端二次确认
2. 前端二次确认后带 `force_workbench_offline=true` 重新请求：
   - 执行软删（`is_deleted=1`）+ 同步下架（`status=0`）
   - 写入 `workbench_item_blocklist`（`module_type='product_publish'`, `item_type='product'`）
   - 写审计日志 `product_workbench_offline`

### 9.2 DELETE `/admin/product-categories/:id`（商品分类软删 · 工作台联动）

**请求参数（query）**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| force_workbench_offline | string | 否 | `true` 或 `1`：确认同步下架分类下所有已发布商品并加入禁止列表；不传则触发二次确认 |

**联动逻辑**

1. 若分类在工作台 `workbench_draft`（`module_type='product_publish'` 且 `publish_status=1`）中已发布，且未传 `force_workbench_offline`：
   - 返回 `409` + `code=40903`（`CATEGORY_WORKBENCH_PUBLISHED`），提示前端二次确认
2. 前端二次确认后带 `force_workbench_offline=true` 重新请求：
   - 跳过"分类下仍有商品"检查，直接下架分类（`status=0`）
   - 分类下所有未删除商品同步下架（`status=0`）并逐一写入 `workbench_item_blocklist`
   - 写审计日志 `category_workbench_offline`（含 `offline_product_count`）

### 9.3 DELETE `/admin/articles/:id`（资讯软删 · 工作台联动 · W7 扩展）

**请求参数（query）**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| force_workbench_offline | string | 否 | `true` 或 `1`：确认同步下架工作台已发布资讯并加入禁止列表；不传则触发二次确认 |

**联动逻辑**

1. 若资讯在工作台 `workbench_draft`（`module_type='article_publish'` 且 `publish_status=1`）中已发布，且未传 `force_workbench_offline`：
   - 返回 `409` + `code=40904`（`ARTICLE_WORKBENCH_PUBLISHED`），提示前端二次确认
2. 前端二次确认后带 `force_workbench_offline=true` 重新请求：
   - 执行软删（`is_deleted=1`）+ 同步下架（`status=0`）
   - 写入 `workbench_item_blocklist`（`module_type='article_publish'`, `item_type='article'`）
   - 写审计日志 `article_workbench_offline`

### 9.4 新增错误码（40901–40905）

| HTTP | code | 常量名 | 说明 |
|------|------|--------|------|
| 409 | 40901 | `PRODUCT_WORKBENCH_PUBLISHED` | 商品已在工作台发布，软删前需二次确认 |
| 409 | 40902 | `PRODUCT_WORKBENCH_BLOCKED` | 商品已被禁止再次发布（信息注册台软删联动下架） |
| 409 | 40903 | `CATEGORY_WORKBENCH_PUBLISHED` | 商品分类已在工作台发布，软删前需二次确认 |
| 409 | 40904 | `ARTICLE_WORKBENCH_PUBLISHED` | 资讯已在工作台发布，软删前需二次确认（W7 扩展） |
| 409 | 40905 | `ARTICLE_WORKBENCH_BLOCKED` | 资讯已被禁止再次发布（W7 扩展） |

**响应示例（40901）**

```json
{
  "code": 40901,
  "message": "该商品已在小程序工作台发布，软删除将同步下架且不可再次发布，请确认后重试",
  "data": null
}
```

> 错误码 `40901`–`40905` 需三端同步：后端 `businessCodes.js`、管理端 `constants/errorCodes.ts`、小程序 `constants/errorCodes.js`。
