## 1. 用户模块

共 11 张表，管理用户账户、资料、登录记录、地址等核心信息。

### 1.1 user_account - 用户账户表

**用途**: 存储用户核心账户信息，作为用户身份的唯一标识。

| 字段名 | 类型 | 是否必填 | 默认值 | 说明 |
|--------|------|----------|--------|------|

| create_time | DATETIME | 是 | NOW() | 创建时间 |
| last_login_time | DATETIME | 否 | NULL | 最后登录时间 |
| is_hidden | BOOLEAN | 是 | FALSE | 是否隐藏 |
| hidden_at | DATETIME | 否 | NULL | 隐藏时间 |
| hidden_by | BIGINT | 否 | NULL | 隐藏操作人admin_id |
