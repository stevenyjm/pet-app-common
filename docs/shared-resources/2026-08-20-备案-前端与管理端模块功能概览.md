# 前端与管理端模块功能概览

> **文档类型**：备案（系统功能概览）
> **创建日期**：2026-08-20
> **适用范围**：宠物生鲜电商项目 — 小程序前端（pet-app）、商户管理端（pet-app-admin-web）
> **说明**：本文档对当前两端已实现的模块与功能进行简要盘点，便于跨项目协作时快速了解能力边界。详细接口规范见 `pet-app-common/docs/api-specs/`，详细需求见 `pet-app-common/docs/requirements/`。

---

## 一、小程序前端（pet-app）

技术栈：Taro + Vue3，编译目标微信小程序，自定义底部导航。

### 1.1 主包 Tab 页面（5 个一级入口）

| Tab | 页面路径 | 功能说明 |
|-----|---------|---------|
| 首页 | `pages/index/index` | 首屏内容聚合，按需登录入口 |
| 商城 | `pages/mall/mall` | 商品列表、分类浏览、扫码检索 |
| 宠物 | `pages/pet/pet` | 当前用户宠物档案列表与快捷入口 |
| 订单 | `pages/order/order` | 订单列表、状态筛选、删除（软删除） |
| 我的 | `pages/mine/mine` | 个人中心、资料卡片、功能入口聚合 |

### 1.2 分包模块（13 个分包）

| 分包 | 页面 | 功能说明 |
|------|------|---------|
| subpk-auth | login / qr-confirm | 微信登录、小程序码登录确认 |
| subpk-cart | cart | 购物车增删改查、库存校验 |
| subpk-message | index | 用户消息中心 |
| subpk-product | detail | 商品详情、SKU 选择、营养信息 |
| subpk-order | detail / checkout / review | 订单详情、结算、评价 |
| subpk-pet | info / meal-record / exercise-record | 宠物详情、餐食记录、运动记录 |
| subpk-news | list / detail / favorites / webview | 资讯列表、详情、收藏、外部链接 |
| subpk-address | list / edit | 收货地址列表与编辑 |
| subpk-reminder | list / edit | 日常提醒标签与管理 |
| subpk-feedback | index / history | 意见反馈提交与历史 |
| subpk-service | chat | 在线客服会话 |
| subpk-settings | index | 用户设置 |
| subpk-info | index | 关于我们 |

### 1.3 公共组件

`PageNavBar`、`TabNavBar`、`PageLoading`、`LoginAgreement`、`QrShareSheet`、`FoodNutritionForm`、`GenderIcon`、`InfoMiniCard`、`PetAddWizard`、`PetHeroPreview`、`MessageBubble`、`OrderPicker`、`ServiceOrderCard`、`ServiceProductCard`、`TabPageSheet` 等。

### 1.4 API 模块

`pet.js`（宠物档案与日记录）、`product.js`（商品/SKU/扫码）、`order.js`（订单 CRUD/评价/删除）、`cart.js`（购物车）、`user.js`（用户资料与设置）等。

## 二、商户管理端（pet-app-admin-web）

技术栈：Vue3 + Vite + Element Plus + Vue Router，支持 Web 与 Electron 双形态。

| 菜单 | 路径 | 权限 | 功能说明 |
|------|------|------|---------|
| 仪表盘 | `/dashboard` | `dashboard:view` | 商户首页关键经营指标概览 |

## 三、权限与访问控制

- 管理端采用基于角色的权限控制（RBAC），路由 `meta.permission` 与后端权限码对齐，`super_admin` 拥有全量权限（`*`）。
- 小程序前端 C 端 API 响应字段使用 snake_case；管理端 API 响应字段使用 camelCase。
- 跨项目字段命名、时间字段、错误码对齐细则见 `pet-app-common/docs/shared-rules/cross-project.master.md`。
