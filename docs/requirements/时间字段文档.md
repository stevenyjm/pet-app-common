## 四、API 响应时间字段详解

### 4.1 认证模块

#### 登录响应

**接口**: `POST /api/v1/auth/login`

| 响应字段 | 来源 | 格式 | 说明 |
|----------|------|------|------|
| `token` | 后端生成 | JWT 字符串 | 无时间概念 |
| `expiresIn` | 后端生成 | 数字（秒） | 过期时间数值 |
| `refreshToken` | 后端生成 | JWT 字符串 | 无时间概念 |
| `refreshTokenExpiry` | 后端生成 | 数字（秒） | 过期时间数值 |

**用户信息**:

| 响应字段 | 来源 | 格式 | 数据库字段 | 时区问题 |
|----------|------|------|-----------|---------|
| `createdAt` | `utils/userInfo.js` | ISO 8601 (`2026-06-29T10:30:00.000Z`) | `user_account.create_time` | ⚠️ 使用 UTC |

```javascript
// utils/userInfo.js - 问题代码
const createdAt = account.create_time
  ? new Date(account.create_time).toISOString()
  : undefined;
```

**前端解析**:
```javascript
// JavaScript
const createdAt = new Date(response.createdAt); // 获得 UTC 时间
// 或使用日期库 moment.js / dayjs
dayjs(response.createdAt).format('YYYY-MM-DD HH:mm:ss');
```

### 4.4 订单模块

#### 获取订单详情

**接口**: `GET /api/v1/orders/:order_id`

| 响应字段 | 来源 | 格式 | 数据库字段 | 时区问题 |
|----------|------|------|-----------|---------|
| `createdAt` | `formatDateTime()` | `YYYY-MM-DD HH:mm:ss` | `order_main.create_time` | ⚠️ UTC 本地时间 |
| `paidAt` | `formatDateTime()` | `YYYY-MM-DD HH:mm:ss` 或 NULL | `order_main.pay_time` | ⚠️ UTC 本地时间 |
| `expireAt` | `getExpireAt()` | ISO 8601 (`2026-06-29T18:30:00.000Z`) | 计算生成 | ⚠️ UTC ISO |
| `shippedAt` | `formatDateTime()` | `YYYY-MM-DD HH:mm:ss` 或 NULL | `order_main.shipped_at` | ⚠️ UTC 本地时间 |

```javascript
// utils/orderHelpers.js - 问题代码
function formatDateTime(value) {
  const date = new Date(value); // 使用服务器本地时区（UTC）
  return `${date.getFullYear()}-${pad(date.getMonth() + 1)}...`;
}

function getExpireAt(order) {
  return new Date(order.expire_at).toISOString(); // 返回 UTC ISO
}
```

**前端解析**:
```javascript
// 解析 createdAt (YYYY-MM-DD HH:mm:ss)
const date = new Date(response.createdAt.replace(' ', 'T') + 'Z');

// 解析 expireAt (ISO 8601)
const expireDate = new Date(response.expireAt);
```
