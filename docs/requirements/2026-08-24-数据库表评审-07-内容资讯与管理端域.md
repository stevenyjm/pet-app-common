### C. 其他已决策规则

| 规则 | 决策结果 |
|------|----------|
| 时间字段维护方式 | 后端主动推送（移除 DB 自动维护） |
| CONSTRAINT 约束 | 全量移除（引用完整性由后端校验） |
| 字段表源前缀 | 仅易混淆字段加前缀（`status`→`{entity}_status`、`name`→`{entity}_name`、`description`→`{entity}_description`、`type`→`{entity}_type`）；通用字段（`phone`、`email`、`avatar_url`、`create_time` 等）不加 |
| `is_deleted` 索引 | 移除单列索引；联合索引中 TINYINT 不作首列；含唯一索引的表若需"删除后重建"，在唯一索引中加入 `is_deleted` 或走 un-delete |
| COMMENT | 表级与字段级 COMMENT 均不可省略；枚举字段标注取值映射 |
| TEXT/JSON 类型 | 避免使用；短文本用 VARCHAR(n)，数组用子表，结构化对象用扁平字段或子表；若触发分表须先向用户确认 |

```sql
CREATE TABLE IF NOT EXISTS `article` (
  `article_id` VARCHAR(32) NOT NULL COMMENT '主键（业务编码）',
  `type` VARCHAR(16) NOT NULL,
  `tag` VARCHAR(32) DEFAULT NULL,
  `title` VARCHAR(128) NOT NULL,

  `cover_theme` VARCHAR(16) DEFAULT NULL,
  `cover_emoji` VARCHAR(8) DEFAULT NULL,
  `content_json` TEXT NOT NULL,
  `position` VARCHAR(16) NOT NULL DEFAULT 'home',
  `sort_order` INT NOT NULL DEFAULT 0,
  `views` INT NOT NULL DEFAULT 0,
  `status` TINYINT NOT NULL DEFAULT 1 COMMENT '业务状态：1-已发布 0-草稿',
  `published_at` DATETIME DEFAULT NULL COMMENT '业务发布时间',
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间（北京时间）',
  `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '最后更新时间（北京时间）',

  KEY `idx_position_status_sort` (`position`, `status`, `sort_order`)

```

#### 备注说明

- `article_id` 已是 VARCHAR(32) 业务编码，但命名为 `_id` 不符合 D1 主键命名规范（应 `article_code`）
- `type`、`status` 为易混淆字段，未加表源前缀，违反 D2
- `created_at` / `updated_at` 命名不符 D3（应为 `create_time` / `last_modified_time`），且使用 `DEFAULT CURRENT_TIMESTAMP` / `ON UPDATE CURRENT_TIMESTAMP`，违反 D3 维护方式
- `content_json` 使用 TEXT 类型存储资讯富文本内容，违反 D7（建议改子表 `article_content_block` 分块存储）
- `type`、`tag`、`title`、`summary`、`cover_url`、`cover_theme`、`cover_emoji`、`position`、`sort_order`、`views` 等字段缺失 COMMENT，违反 D8

  `page_id` INT NOT NULL AUTO_INCREMENT COMMENT '主键',
  `type` VARCHAR(16) NOT NULL COMMENT 'user|privacy|about|merchant',
  `title` VARCHAR(128) NOT NULL,
  `content_json` TEXT NOT NULL,
