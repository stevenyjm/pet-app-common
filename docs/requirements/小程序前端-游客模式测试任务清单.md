## 1. 测试环境与准备

### 1.1 启动项目

| 步骤 | 操作 | 预期 | 验证结果 |
|------|------|------|----------|
| 1 | 在项目根目录执行 `npm install`（首次） | 依赖安装成功 | 符合预期 |

### 1.2 进入游客模式

| 步骤 | 操作 | 预期 | 验证结果 |
|------|------|------|----------|
| 1 | 冷启动小程序 | 进入首页 Tab | 首页 Tab 正常显示，**不**跳转登录页 |
| 2 | 点击「我的」Tab | 展示登录引导卡片 | 展示登录引导卡片，**不**跳转登录页 |

| 4 | 检查 Storage | `zzp_guest_mode` = '1'，无 `zzp_access_token` | `zzp_guest_mode` = '1'，无 `zzp_access_token` 键值对 |

### 1.3 测试验证要点

- [ ] 打开「调试器 → Storage」，观察 `zzp_guest_mode`、`zzp_access_token` 等键值
- [ ] 打开「调试器 → Network」，观察 API 请求是否携带 Token（游客模式不应携带）
- [ ] 每条用例记录：**步骤 / 实际结果 / 截图或 Network 截图 / 缺陷编号**
