## 1. 测试环境与准备

### 1.1 启动项目

| 步骤 | 操作 | 预期 | 验证结果
|------|------|------|
| 1 | 在项目根目录执行 `npm install`（首次） | 依赖安装成功 | 依赖安装完成
| 2 | 执行 `npm run dev:mp-weixin` | 编译成功，生成 `dist/dev/mp-weixin` | 编译成功，输出正常
| 3 | 微信开发者工具 → 导入项目 → 选择上述目录 | 冷启动首屏为**首页 Tab**（非登录页） | 
| 4 | AppID 使用 `wx3aa2757710973eb2`（**正式号**，见 `manifest.json`） | 可正常预览 | 

### 1.2 API 联调模式

| 模式 | 命令 / 配置 | API 基址 | 适用场景 |
|------|-------------|----------|----------|
| 本地后端 | `npm run dev:mp-weixin` + `.env.development` | `http://localhost:8080/api/v1` | 本地联调 |
| 真机局域网 | 复制 `.env.development.local.example` 为 `.env.development.local`，填写本机 IP | `http://192.168.x.x:8080` | 手机预览 |
| 云端直连 | `npm run dev:mp-weixin:cloud` + `.env.cloud-dev` | 云端 HTTPS | Sealos / 生产环境联调 |

**开发者工具设置建议**：

- [ ] 勾选「不校验合法域名、web-view、TLS 版本」（本地 HTTP 联调时必需）
- [ ] 打开「调试器 → Network」，观察请求 URL、`code` 业务码、`statusCode`
- [ ] 打开「调试器 → Storage」，观察 Token、游客标记等本地键值

### 1.3 测试账号与角色矩阵

建议在每种角色下各跑一轮核心流程：

| 角色 | 进入方式 | 可测范围 |
|------|----------|----------|
| **未登录浏览** | 清除 Storage 后冷启动 | 首屏首页 Tab；5 Tab 可浏览；去结算等写操作提示登录 |
| **游客模式** | 登录页点击「暂不登录，先看看」 | 写入 `zzp_guest_mode`；「我的」昵称「游客用户」+ 游客模式横幅；写操作提示登录 |
| **已登录新用户** | 微信一键登录（`is_new_user=true`） | 登录后自动进宠物 Tab，应弹出添宠向导 |
| **已登录老用户** | 已有宠物/订单的账号 | 全功能（含写操作、支付联调） |

## 10. 端到端业务流程（推荐冒烟顺序）

按下列顺序在**已登录 + 云端 API** 环境下执行一轮完整冒烟：

| 序号 | 流程 | 关键路径 | 验证点 |
|------|------|----------|--------|
| E1 | 注册登录 | 登录 → 宠物 Tab | Token 写入、新用户向导 |
| E2 | 添宠建档 | 向导完成 → 档案页查看 | 宠物列表、证件状态、陪伴时长 |
| E3 | 饮食记录 | 记一餐 → 模板 → 每日状态 | 日记录持久化、切换日期 |
| E4 | 浏览购买 | 商城 → 详情 → 加购 → 购物车 | SKU、数量、角标 |
| E5 | 下单支付 | 购物车 → 确认订单 → 支付 | 地址、订单创建、支付回调 |
| E6 | 履约闭环 | 订单列表 → 物流 → 确认收货 → 评价 | 状态流转 10→20→30→40 |
| E7 | 售后 | 已完成订单申请售后 → 查看进度 | 售后状态 |
| E8 | 再来一单 | 已完成订单再来一单 → 购物车 | 批量加购 |
| E9 | 账户设置 | 邮箱/邀请码/提醒/地址 | 各 PUT/POST 成功 |
| E10 | 反馈客服 | 提交反馈 → 历史；订单联系客服 | 反馈列表、客服会话 |
| E11 | 消息 | 触发业务消息后查看消息中心 | 分类、已读、跳转 |
| E12 | 退出 | 设置退出登录 | 态清除，Tab 需重新登录 |

## 12. Mock / Fallback 联调注意

以下场景在 **API 失败** 时可能展示演示数据，测试时需主动区分「真数据」与「Mock」：

| 模块 | Fallback 行为 | 测试建议 |
|------|---------------|----------|
| 订单 `order.js` | `MOCK_ORDERS` + 本地订单 | 断网时核对订单号是否为演示单号 |
| 购物车 `cart.js` | `MOCK_CART_ITEMS` | 核对商品是否与后台一致 |
| 地址 `address.js` | 本地 `zzp_local_addresses` | 多端同步时重点测实网 |
| 宠物 `pet.js` | mock-1~3 宠物 | 除 40408 外可能静默 Mock |
| 消息 `message.js` | `MOCK_MESSAGES` | 断网时消息内容可能为假 |
| 商品/资讯 | 静态 mall/news | 浏览类可接受 |

**建议**：正式验收使用 `npm run dev:mp-weixin:cloud` 且保持网络畅通；刻意断网用例单独标记为「降级测试」。
