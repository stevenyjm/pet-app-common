## 1. 需求概述

将「我的」页面从平铺式布局改造为卡片化布局，提升视觉层次与信息密度。

| # | 需求摘要 | 状态 |
|---|----------|------|
| D1 | 用户资料区域改为圆角卡片（头像、昵称、认证状态、编辑入口） | ✅ 已实现 |
| D2 | 订单入口改为横向滑动卡片组（待付款、待发货、待收货、待评价、退款/售后） | ✅ 已实现 |
| D3 | 常用功能入口改为网格卡片组（优惠券、地址管理、积分商城等） | ✅ 已实现 |
| D4 | 底部增加服务协议、关于我们等链接 | ✅ 已实现 |
| D5 | 卡片间距统一为 `24rpx`；圆角统一为 `16rpx` | ✅ 已实现 |

---

## 2. 布局结构

```text
<view class="page-mine">
  ├─ 用户资料卡片
  │   ├─ 头像（96rpx 圆）
  │   ├─ 昵称 + 认证标识
  │   ├─ 编辑资料入口
  │   └─ 积分 / 优惠券 快捷入口
  │
  ├─ 订单入口卡片（横向滑动）
  │   └─ scroll-view（可滑动，5 项）
  │       ├─ 待付款
  │       ├─ 待发货
  │       ├─ 待收货
  │       ├─ 待评价
  │       └─ 退款/售后
  │
  ├─ 常用功能卡片（网格）
  │   ├─ 优惠券
  │   ├─ 地址管理
  │   ├─ 积分商城
  │   ├─ 联系客服
  │   ├─ 我的收藏
  │   └─ 设置
  │
  └─ 底部链接区
      ├─ 用户协议
      ├─ 隐私政策
      └─ 关于我们
```

## 3. 样式规格

| 项 | 规格 |
|----|------|
| 卡片圆角 | `border-radius: 16rpx` |
| 卡片间距 | `margin-bottom: 24rpx` |
| 卡片阴影 | `box-shadow: 0 4rpx 12rpx rgba(0,0,0,0.05)` |
| 背景色 | `background: #FFFFFF` |
| 页面背景 | `background: #F5F5F5` |

---

## 4. 实现要点

1. **用户资料卡片**：头像使用 `clip-path: circle(48rpx)`；认证标识使用 `iconfont`
2. **订单入口**：`scroll-view` 横向滑动，每项 `flex-shrink: 0`；badge 角标显示待处理数量
3. **功能网格**：`grid-template-columns: repeat(3, 1fr)`；每项含图标 + 文案
4. **响应式**：适配不同屏幕宽度
