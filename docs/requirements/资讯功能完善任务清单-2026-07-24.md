1. **登录后同步**：用户登录成功后，检查本地 `zzp_favorite_articles` 存储

## 3. P1 优先级任务

### 3.1 阅读量统计去重

**需求来源**：当前阅读量每次访问详情页自动 +1，无去重机制，同一用户重复访问会重复计数。

#### 3.1.1 技术方案

采用 **Redis 基于用户的每日去重** 方案：

| 场景 | 去重 Key | TTL |
|------|---------|-----|
| 已登录用户 | `article:view:{articleId}:{userId}:{date}` | 24小时 |
| 未登录用户 | `article:view:{articleId}:{ip}:{userAgentHash}:{date}` | 24小时 |

**流程**：
1. 用户访问资讯详情页
2. 后端生成去重 Key（基于用户 ID 或 IP+UA）
3. Redis SETNX 尝试设置 Key
4. 设置成功 → 数据库 views +1
5. 设置失败 → 跳过计数

#### 3.1.2 后端任务（BE）

| 任务编号 | 任务描述 | 涉及文件 | 验收标准 |
|---------|---------|---------|---------|
| BE-VIEW-01 | 使用现有 Redis 配置 | `utils/redisClient.js` | 无需新增配置，直接使用已有 RedisClient |
| BE-VIEW-02 | 创建阅读量去重服务 | `services/articleViewService.js` | 包含 `recordView` 方法，支持去重和降级 |
| BE-VIEW-03 | 修改资讯详情接口 | `controllers/articleController.js` | 调用去重服务，修复旧值返回 bug |
| BE-VIEW-04 | 处理 Redis 不可用降级 | `services/articleViewService.js` | Redis 故障时直接计数 |

#### 3.1.3 修复阅读量旧值 Bug

**问题**：当前 `getArticle` 中 `row.increment('views')` 后直接返回 `formatArticleRow(row)`，使用的是递增前的旧值。

**修复方案**：
```javascript
// 修复前
await row.increment('views');
return success(res, formatArticleRow(row));

// 修复后
await row.increment('views');
await row.reload(); // 重新加载最新数据
return success(res, formatArticleRow(row));
```

#### 3.1.4 向后兼容性

- 不影响现有 views 数据
- Redis 不可用时自动降级为原有逻辑
- 保留原有的 `row.increment('views')` 作为降级方案

```javascript
inlineUrl: raw.inline_url ?? raw.inlineUrl ?? '',
```

管理端预览组件 `ArticleDetailPreview.vue`（第 36-39 行）已支持 `inlineUrl` 渲染，无需修改。

## 7. 风险与注意事项

### 7.1 技术风险

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| 收藏迁移数据冲突 | 本地和后端存在相同收藏 | 唯一索引自动忽略重复，保留后端记录 |
| Redis 不可用 | 阅读量统计异常 | 实现降级逻辑，直接计数（已有 RedisClient.execute 自动降级） |
| 大量收藏数据 | 用户收藏数量过大影响性能 | 分页查询，限制单次查询数量 |

### 7.2 业务风险

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| 阅读量减少 | 去重后统计数值可能下降 | 提前告知业务方，保持数据一致性 |
| 未登录用户去重 | IP 共享导致误判 | 使用 IP+User-Agent 组合，降低误判概率 |

### 7.3 部署风险

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| 收藏表数据迁移 | 新增表影响数据库 | 迁移脚本幂等设计，执行前备份；版本号指定为 v39 |
| API 变更影响小程序 | 后端 API 变更可能影响小程序 | 保持向后兼容，新增 API 而非修改现有；资讯详情接口继续保持公开 |

### 7.4 边缘情况

| 情况 | 处理方式 |
|------|---------|
| 静态 fallback 资讯（数据库查询失败） | 不支持收藏状态，返回 `is_favorited: null` |
| 未登录用户访问 | 阅读量去重基于 IP+UA，收藏状态返回 `false` |
