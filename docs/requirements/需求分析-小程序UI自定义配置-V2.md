# 小程序 UI 自定义配置需求方案（V2）

## 1. 需求概述

### 1.1 需求背景

基于第一轮功能验收测试（T-05）的反馈，商户提出了更精细的 UI 资源配置需求。原有的配置方案仅覆盖了五个页面的背景图片、按钮图标和 InfoMiniCard 卡片背景，未能满足商户对页面内各功能区域的个性化配置需求。本次需求旨在扩展配置范围，增加更多可配置的 UI 资源项。

### 1.2 配置目标扩展

在原有配置基础上，新增以下配置项：

| 序号 | 配置项类别 | 说明 | 涉及页面 |
|------|-----------|------|---------|
| 1 | 商品分类区背景 | 商城左侧分类区整体背景和单个分类背景 | 商城 |
| 2 | 商品展示区背景 | 商城右侧商品展示区背景 | 商城 |
| 3 | 商品卡片背景 | 商城商品卡片统一背景图片 | 商城 |
| 4 | 宠物选项区背景 | 宠物标签页宠物选项展示区背景 | 宠物 |
| 5 | 每日状态栏背景 | 宠物标签页每日状态栏背景 | 宠物 |
| 6 | 日记录卡片背景 | 宠物标签页餐食记录和运动记录卡片背景 | 宠物 |
| 7 | 订单筛选区背景 | 订单标签页筛选行区域背景 | 订单 |
| 8 | 订单卡片背景 | 订单标签页订单卡片统一背景图片 | 订单 |
| 9 | 个人介绍卡片背景 | 我的标签页个人介绍卡片背景 | 我的 |
| 10 | 按钮样式调整 | 邀请码卡片按钮和日常提醒角标背景改为透明 | 我的 |
| 11 | 扫码图标 | 我的标签页左上角扫码图标、添加食物弹窗左上角扫码图标（共用同一资源） | 我的、宠物 |

### 1.3 文档引用

本需求文档是对 [需求分析-小程序UI自定义配置.md](file:///C:/Users/22188/Desktop/宠物生鲜电商开发项目/pet-app-common/docs/requirements/需求分析-小程序UI自定义配置.md) 的补充和扩展，原文档中已完成的配置项（五个页面背景、按钮图标、InfoMiniCard 卡片背景）继续有效。

### 1.4 需求说明

#### 1.4.1 重复项处理

用户原始需求中存在以下重复项，已在本文档中进行合并处理：
- 第6项和第7项：商城标签页商品卡片背景配置，合并为一项
- 第12项和第13项：订单标签页订单卡片背景配置，合并为一项

#### 1.4.2 条件性需求说明

部分需求带有条件性描述（"如果商户管理端不能设置..."），这些配置项的实施需满足以下条件：

| 配置项 | 条件 | 说明 |
|--------|------|------|
| 单个商品分类背景 | 商户管理端不能设置单个分类背景 | 若管理端已有此功能，则无需新增 |
| 商品卡片背景 | 商户管理端不能设置单个商品卡片图片 | 若管理端已有此功能，则无需新增 |

实施前需确认商户管理端当前的配置能力，仅对管理端不支持的配置项进行开发。

> **注**：首页和商城的资讯卡片背景配置已移除，因为商户管理端的资讯编辑页面已支持上传封面图片。

        "productArea": { "background": "https://..." },
        "productCard": { "background": "https://..." }

      "pet": {
        "background": "https://...",

### 4.2 Fallback 方案

#### 4.2.1 通用回退策略

| 场景 | Fallback 策略 |
|------|--------------|
| 背景图片加载失败 | 回退到硬编码的默认背景色或样式 |
| API 请求失败 | 使用本地缓存，缓存也无则使用内置默认 |
| 配置数据结构异常 | 使用内置默认配置 |

#### 4.2.2 特殊回退策略

以下配置项的 fallback 策略为透明显示：

| 配置项 | 配置标识 | Fallback 策略 |
|--------|---------|--------------|
| 商城左侧商品分类区背景 | `pages.mall.categoryArea.background` | 透明 |
| 商城右侧商品展示区背景 | `pages.mall.productArea.background` | 透明 |
| 订单筛选行区域背景 | `pages.order.filterBar.background` | 透明 |

## 7. 注意事项

### 7.1 与原配置的兼容性

新增配置项为可选配置，不影响原有配置项的使用：
- 当新增配置项未设置时，使用默认样式
- 配置版本号从 v2 开始，向后兼容 v1 配置

### 7.2 微信小程序限制

与原需求文档一致，所有远程图片 URL 的域名必须在微信公众平台配置「downloadFile 合法域名」。

### 7.3 性能优化

新增配置项较多，需注意：
- 配置数据缓存策略保持不变（7天）
- 图片按需加载，避免页面加载时并发请求过多图片资源
