## 1. 需求概述

本需求为小程序底部固定导航栏（Tab Bar）的 **V3.0 视觉升级方案**，将现有 2D 平面图标升级为 **3D 立体透视风格**，通过 3D 元素的形态变化与材质发光实现交互反馈。

| # | 需求摘要 | 状态 |
|---|----------|------|
| D1 | 整体视觉风格升级为卡通3D风格（C4D/Blender渲染质感） | 📋 待实现 |
| D2 | 背景图与导航图标融为一体，采用3D微缩场景 | 📋 待实现 |
| D3 | 5个导航元素（首页/购物/宠物/购物车/我的）各对应一个3D主体元素 | 📋 待实现 |
| D4 | 每个元素具备默认（灰色）与激活（彩色+动效）两种状态 | 📋 待实现 |
| D5 | 热区设计：沿用 Phase 1 的圆形热区，由 slot 下的 `circle` 字段决定（向后兼容） | 📋 待实现 |

### 与 Phase 1 实现的差异对比

| 维度 | Phase 1（当前实现） | V3.0（升级目标） |
|------|---------------------|------------------|
| 视觉风格 | 2D平面图标 + 背景图叠加 | 3D立体透视场景，图标与背景融合 |
| 画布尺寸 | 2000×90px（不缩放，裁切） | **2000×90px**（不缩放，裁切），主体元素布局于中央320×90px区域 |
| 交互模型 | 图标切换 + 文字样式变化 | 3D元素形态变化 + 材质发光 + 动效 |
| 热区形状 | 圆形（circle.r） | **圆形（circle.r）**（向后兼容） |
| 导航元素 | 双态PNG图标 | 3D渲染静态PNG或Lottie/Spine序列帧（作为图标资源） |
| 按钮文案 | 代码渲染 `pageName` | **字段保留，可选择不显示** |

## 2. 视平线与透视构图策略

### 2.1 视平线位置

设定在画幅高度的 **10% - 20%** 处（极低视平线），营造仰视微缩场景的视觉效果。

### 2.2 空间分配

| 区域 | 占比 | 说明 |
|------|------|------|
| 天空区 | 上方 80% | 大面积留白，仅保留少量3D质感的云朵或气球；若显示导航文字则为文字预留安全空间，若不显示文字则为3D元素上移动效预留空间 |
| 平原区 | 下方 10%-20% | 作为3D微缩舞台的底座 |

### 2.3 3D对称透视排布（核心）

整体画面采用 **中心对称透视**，营造向心聚拢的视觉焦点。所有主体元素布局于画布中央 320×90px 区域内（对应最窄参照宽度 W_min = 320px），采用与 Phase 1 一致的坐标系 A（底边中点为原点，x 轴向右，y 轴向上）。

| 元素 | 位置 | 旋转方向 | 说明 |
|------|------|----------|------|
| 左侧元素（首页、购物） | 左侧区域（x∈[-160, -80]） | 顺时针旋转 | 正面略微朝向画面右侧（中心） |
| 右侧元素（购物车、我的） | 右侧区域（x∈[80, 160]） | 逆时针旋转 | 正面略微朝向画面左侧（中心） |
| 中心元素（宠物狗狗） | 正中心（x=0） | 无旋转，正面朝向观众 | 作为视觉锚点 |

**布局约束**：5 个导航元素的几何中心（`circle.cx`）在水平方向上均匀分布于中央 320px 区域内，确保在 320px 窄屏裁切窗口内完整可见。

## 3. 导航元素设计与交互状态说明

### 3.1 元素状态总览

V3.0 版本中，所有主体元素作为图标资源使用，沿用 Phase 1 的 slot 配置结构。默认状态对应未选中状态图标（`iconDefault`），激活状态对应选中状态图标（`iconActive`）。

| 导航名称 | 主体元素 | 默认状态（未选中/灰色） | 激活状态（选中/彩色+动效） | 视觉与交互备注 |
|----------|----------|------------------------|---------------------------|----------------|
| 首页 | 3D广告牌 | 灰色轮廓广告牌，牌面无内容，略微向右旋转 | 广告牌亮起霓虹彩灯，显示彩色"首页"字样 | 彩灯带有3D自发光材质（Emission），产生微弱呼吸闪烁 |
| 购物 | 3D购物楼 | 灰色大楼，顶部"MALL"牌子暗淡，略微向右旋转 | 顶部"MALL"牌子变为彩色并高亮发光，窗户透出暖光 | 强调"MALL"牌子的发光特效，激活时体现"营业中"的热闹感 |
| 宠物 | 3D卡通狗狗 | 灰色狗狗蜷缩在花毯上睡觉，正面朝向观众 | 狗狗竖起耳朵开心站立，嘴中咬着一根骨头 | 状态切换带有弹性动效（从蜷缩到站立有"弹起"感），花毯保持不动 |
| 购物车 | 3D购物推车 | 灰色空推车，略微向左旋转 | 推车内装满彩色货物，车轮带微动效 | 激活状态下，货物明显溢出车筐，增强"满载"的获得感 |
| 我的 | 3D住宅与人 | 灰色紧闭的房屋，人站立无动作，略微向左旋转 | 房屋大门打开透出暖光，人物挥手致意 | 强调"归家"的温馨感，门开与挥手需同步 |

### 3.2 按钮文案处理

V3.0 版本中，`pageName`、`labelAnchor`、`labelStyle` 等按钮文案相关字段**保留以保持向后兼容**，但实际使用时**可选择不渲染按钮文案**。当不需要显示文案时，可通过以下方式处理：

| 处理方式 | 说明 |
|----------|------|
| 不渲染 | 在代码层面跳过 `dock-label` 元素的渲染逻辑 |
| 透明度隐藏 | 将 `labelStyle.default.active.color` 设置为透明 |
| 字号为0 | 将 `labelStyle.default.active.fontSize` 设置为 0 |

### 3.3 动效规格

| 元素 | 动效类型 | 实现建议 |
|------|----------|----------|
| 首页霓虹灯 | 呼吸闪烁 | 3D渲染时输出发光遮罩层，前端控制透明度变化 |
| 购物MALL牌 | 高亮发光 | 单独输出Glow Pass图层，代码控制透明度 |
| 宠物狗狗 | 弹性弹起 | Lottie/Spine序列帧实现蜷缩→站立的弹性过渡 |
| 购物车货物 | 微动效 | 货物轻微晃动或车轮缓慢转动 |
| 我的房屋 | 门开+挥手 | 门开动画与人物挥手动作同步 |

## 4. 点击交互的位置定位（热区设计）

V3.0 版本沿用 Phase 1 的圆形热区设计，由 slot 配置中的 `circle` 字段（`{ cx, cy, r }`）决定，保持向后兼容性。

### 4.1 热区定义

| 项 | 规格 | 说明 |
|----|------|------|
| 形状 | **圆形** | 与 Phase 1 保持一致 |
| 圆心 | `circle.cx`, `circle.cy` | 坐标系 A（底边中点为原点） |
| 半径 | `circle.r` | 可根据元素尺寸调整 |
| 最小尺寸 | **44px** | 当 `2×r < 44px` 时扩展至 44px |

### 4.2 热区布局约束

| 规则 | 说明 |
|------|------|
| 几何约束 | 热区圆心由 `circle` 字段定义，不受3D元素视觉旋转影响 |
| 元素居中 | 3D元素在各自的圆形热区内保持视觉居中 |
| 边界约束 | 旋转后的元素边缘不得超出热区边界，防止相邻元素热区重叠导致误触 |
| 窄屏可见 | 在 320px 窄屏裁切窗口内，所有热区圆心均须完整可见 |

### 4.3 坐标系与换算

热区坐标采用与 Phase 1 一致的坐标系 A，代码端经 `coordinate.js` 统一换算至画布像素：

```text
px = 1000 + cx
py = 90 - cy
pr = r
```

其中 `(px, py)` 为画布左上角原点下的像素坐标，`pr` 为热区半径（像素）。

## 5. 设计与开发注意事项

### 5.1 3D渲染输出

- 建议将5个元素在同一个3D场景中统一渲染，以保证全局光照、阴影和透视的一致性
- 导出格式：
  - 静态状态：带透明通道的PNG
  - 动效状态：Lottie或Spine序列帧

### 5.2 MALL牌子发光处理

激活状态的"MALL"牌子发光效果，建议在渲染时单独输出一层"发光遮罩（Glow Pass）"，前端可通过代码控制该图层的透明度来实现平滑的呼吸灯效果。

### 5.3 防误触测试

由于左右两侧元素有旋转，视觉上的重心可能会偏移。真机测试时需重点验证：
- "旋转后的视觉中心"与"圆形热区中心"是否对齐
- 必要时微调元素在热区内的偏移量

### 5.4 安全区预留

所有元素的最高点（广告牌彩灯、MALL牌子、站立狗狗头顶）距离画幅顶部至少保留 **15px**，防止被手机刘海遮挡。

## 6. 实施建议

### 6.1 开发阶段

| 阶段 | 内容 | 依赖 |
|------|------|------|
| 资产准备 | 3D建模与渲染，输出各元素的默认/激活状态图片及动效资源 | 设计组完成3D模型 |
| 集成开发 | 将3D资源替换现有2D图标，实现热区与交互逻辑 | 资产准备完成 |
| 动效实现 | 集成Lottie/Spine动效，实现状态切换动画 | 集成开发完成 |
| 测试验证 | 防误触测试、安全区测试、动效流畅度测试 | 动效实现完成 |

### 6.2 与现有架构的兼容性

V3.0 升级可复用现有 Phase 1 的以下架构组件，保持高度向后兼容：

| 组件 | 复用情况 | 说明 |
|------|----------|------|
| `BottomDock.vue` | **完全复用** | 无需调整热区形状 |
| `primaryNav.js` | **完全复用** | 路由策略 R1/R2 不变 |
| `layout.js` | **完全复用** | 布局常量无需调整 |
| `coordinate.js` | **完全复用** | 热区换算逻辑不变 |
| `dock.theme.json` | **兼容复用** | slot 配置结构不变，仅替换图标资源 |

需新增/修改的内容：
- **视觉资产文件**：将 2D 图标替换为 3D 渲染资源（`iconDefault` / `iconActive`）
- **可选修改**：如需隐藏按钮文案，可在 `BottomDock.vue` 中添加条件渲染逻辑

**向后兼容说明**：
- V3.0 版本的 slot 配置结构与 Phase 1 完全一致，`circle`、`labelAnchor`、`labelStyle` 等字段定义不变
- 热区逻辑沿用 Phase 1 的圆形热区，由 `circle` 字段决定
- `pageName`、`labelAnchor`、`labelStyle` 等按钮文案字段保留，可选择不渲染
