## 4. 产品方案（已确认）

### 4.1 会话模型：每用户一线程 + 订单上下文

- **一个 C 端用户 ↔ 单商户**：仅维护 **一条主会话**（`service_conversation`）。
- **不按订单拆会话**；订单通过 **`active_order_id`** 与消息级 **`related_order_id`** 区分上下文。
- **商品咨询**：可选 `active_product_id`；顶部展示商品卡片（非订单）。

```
用户 A ──(1:1)── service_conversation ──(N:1 optional)── order_main
                      │
                      ├── active_order_id   → 当前咨询订单（可切换）
                      ├── active_product_id → 商品咨询（可空）
                      └── service_message × N
                              └── related_order_id → 发送时默认 = active_order_id
```

### 4.2 订单上下文四层机制

| 层级 | 机制 | 小程序 | Web 管理端 |
|------|------|--------|------------|
| ① 入口上下文 | URL 参数 `orderId` / `productId` | 打开会话时 `open` 写入活跃上下文；顶部卡片 | 列表项展示最近关联订单号 |
| ② 活跃订单 | `active_order_id` 可切换 | 「切换咨询订单」→ 本人订单列表选择 | 侧栏展示 + 商户可改绑 |
| ③ 消息级关联 | `related_order_id` | 发送时自动带入当前活跃订单 | 气泡旁订单角标（P1） |
| ④ 检索 | 按 `order_no` 搜会话 | — | 会话列表搜索框 |

### 4.3 小程序页面与入口

| 入口 | 路由 | 行为 |
|------|------|------|
| 订单详情/列表「联系客服」 | `/pages/service/chat?orderId={id}` | `open` 设置 `active_order_id` |
| 商品详情「客服」 | `/pages/service/chat?productId={id}` | 设置 `active_product_id` |
| 通用（若未来增加） | `/pages/service/chat` | 无活跃订单，通用咨询 |

**页面结构**（对齐 `prototype/contact-service-prototype.html`）：

```
┌ ← 联系客服 ─────────────┐
├ 商户信息条（在线+服务时间）┤  ← C4：仅展示 9:00–21:00，无自动回复
├ 关联订单/商品卡片（可切换）┤  ← C2
├ 对话区（时间戳+文字/图片） ┤
└ 输入栏 + 拍摄/相册 ──────┘
```

### 4.4 服务时间展示（C4）

- 小程序顶栏 / 商户信息条展示：**服务时间 9:00 – 21:00**（文案可配置，来源 `shop_config` 或常量）。
- **本期不实现**非服务时间内自动回复、机器人应答 → 📋 **二期 P2**。

### 4.5 与用户反馈的边界（C6 · §7）

| 场景 | 路径 | 形态 |
|------|------|------|
| 订单物流/质量等需即时沟通 | **联系客服** → IM | 实时双向 |
| 功能建议、体验吐槽、非紧急 | **用户反馈** → 表单工单 | 异步一次性回复 |
| 已确定退款/退货 | **申请售后** | 状态机流程 |
| 发货/支付状态变更 | **消息中心** | 系统单向通知 |

**入口文案固定**：

- 「联系客服」 / 「💬 客服」→ `pages/service/chat`
- 「用户反馈」→ `pages/feedback/index`
- 「申请售后」→ 售后流程页

## 5. Web 管理端方案（已确认 C3）

### 5.1 信息架构

**路由**：`/customer-service`（侧栏「在线客服」，与「用户反馈」并列）

```
/customer-service
├─ 左栏：会话列表（待回复 / 全部）
│     搜索：昵称、手机号、订单号
│     项：头像、昵称、最后消息、时间、未读角标、关联订单号
├─ 中上：内置标签页 ConversationTabBar（最多 8 个）
├─ 中栏：当前标签会话 · 聊天区
│     顶栏：用户信息 + 活跃订单
│     消息流 + 输入 + 图片上传
└─ 右栏（可折叠）：OrderContextPanel
      订单摘要、跳转订单详情/发货/售后、切换用户其他订单
```

### 5.2 内置标签页规则（C3）

| 规则 | 说明 |
|------|------|
| 打开方式 | 列表点击会话 → 若无标签则新建，若已存在则激活 |
| 上限 | **8** 个标签；超出时关闭最早非当前标签或提示 |
| 未读 | 标签上显示 `unread_admin`；进入会话后调 `read` |
| 关闭 | 可关闭单个标签；关闭当前标签时激活相邻标签 |
| 持久化 | 本期仅内存态；刷新页面清空（P2 可 localStorage 恢复） |

### 5.3 与用户反馈页差异

| 维度 | 用户反馈 `/feedback` | 在线客服 `/customer-service` |
|------|----------------------|------------------------------|
| 数据表 | `user_feedback` | `service_conversation` + `service_message` |
| 排序 | 提交时间 | **最后消息时间** |
| 处理 | 回复 + 标记已处理（终态） | **持续对话** |
| 多开 | 单抽屉 | **多标签页** |

## 6. 技术方案

### 6.1 数据库（Schema v16 建议）

#### 表 `service_conversation`

| 字段 | 类型 | 说明 |
|------|------|------|
| `conversation_id` | BIGINT PK AI | |
| `user_id` | BIGINT FK | `user_account` |
| `merchant_id` | INT | 一期固定 `1` |
| `active_order_id` | BIGINT NULL FK | 当前咨询订单 |
| `active_product_id` | BIGINT NULL FK | 商品咨询 |
| `status` | TINYINT | `1=open` `2=closed`（本期仅用 open） |
| `last_message_at` | DATETIME | 列表排序 |
| `last_message_preview` | VARCHAR(200) | 列表摘要 |
| `unread_admin` | INT DEFAULT 0 | 商户未读 |
| `unread_user` | INT DEFAULT 0 | 用户未读 |
| `create_time` / `update_time` | DATETIME | |

**约束**：`UNIQUE KEY uk_user_merchant (user_id, merchant_id)`

#### 表 `service_message`

| 字段 | 类型 | 说明 |
|------|------|------|
| `message_id` | BIGINT PK AI | |
| `conversation_id` | BIGINT FK | |
| `sender_role` | ENUM | `user` / `admin` / `system` |
| `content_type` | ENUM | `text` / `image` |
| `content` | TEXT | 文本或图片 URL |
| `related_order_id` | BIGINT NULL | 发送时快照 |
| `create_time` | DATETIME | |

**索引**：`(conversation_id, create_time)`、`(related_order_id)`（检索）

### 6.2 C 端 API（Bearer User JWT）

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/service/conversations/open` | 创建或获取会话；body: `order_id?`, `product_id?`；有参则更新 active 上下文 |
| GET | `/service/conversations/current` | 当前用户会话 + 活跃订单/商品摘要 + `unread_user` |
| GET | `/service/conversations/{id}/messages` | 分页历史；`before_id` / `page_size` |
| POST | `/service/conversations/{id}/messages` | 发送消息；body: `content_type`, `content` |
| PUT | `/service/conversations/{id}/active-order` | 切换活跃订单；body: `order_id`（须属当前用户） |
| PUT | `/service/conversations/{id}/active-product` | 切换活跃商品；body: `product_id` |
| POST | `/service/conversations/{id}/read` | 用户已读；`unread_user` 清零 |

**发送消息副作用**：

- `unread_admin++`，更新 `last_message_*`
- 校验：`content` 文本 ≤500 字；图片须为本用户 `storage` 上传 URL

### 6.3 管理端 API（Bearer Admin JWT）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/admin/service/conversations` | 列表；`tab=unread|all`、`keyword`、`order_no`、`page` |
| GET | `/admin/service/conversations/{id}` | 详情：用户资料 + 活跃订单/商品 + 未读数 |
| GET | `/admin/service/conversations/{id}/messages` | 消息分页 |
| POST | `/admin/service/conversations/{id}/messages` | 商户回复 |
| PUT | `/admin/service/conversations/{id}/active-order` | 商户修正关联订单 |
| POST | `/admin/service/conversations/{id}/read` | 商户已读；`unread_admin` 清零 |
| GET | `/admin/stats/dashboard` | 扩展字段 `pending_service_count`（`unread_admin>0` 会话数） |

### 6.4 商户回复 · 离线消息（C5）

当 Admin `POST …/messages` 成功且需通知用户时：

1. 写 `service_message`（`sender_role=admin`）。
2. `unread_user++`（用户未在会话页时由小程序 read 清零）。
3. **若用户不在线会话页**（由后端统一写，不依赖前端上报）：
   - 调用 `messageService.create` 写入 `user_message`：
     - `category = 1`（**系统**）
     - `message_type = service_reply`
     - `title`：如「客服回复了您的消息」
     - `content`：回复摘要（前 80 字）
     - `action_path`：`pages/service/chat`
     - `extra.snapshot`：`{ conversation_id, order_no?, preview }`
     - 幂等键：`service_reply:{message_id}`

> **说明**：用户在会话页内时，通过 **轮询/WebSocket** 直接拉取新消息；`user_message` 主要服务「离开会话后」在消息中心看到提醒。消息中心 **不新增 Tab**，归入现有 **系统** 分类。

### 6.5 实时策略

| 端 | 本期（P0） | 增强（P1） |
|----|------------|------------|
| 小程序会话页 | **3s 轮询** `messages?after_id=` | WebSocket / 长连接 |
| Web 工作台 | **5s 轮询** 当前标签 + 列表未读数 | SSE 或 WebSocket |
| 仪表盘待办 | `pending_service_count` 随轮询或进入页刷新 | 推送刷新 |

### 6.6 Storage

- 新增上传分类：`category=service`
- objectKey：`uploads/service/{user_id}/{uuid}.jpg`
- 限制：单张 ≤5MB；会话内图片消息 ≤9 张/分钟（防刷，可配置）

### 6.7 错误码（建议）

| code | HTTP | 说明 |
|------|------|------|
| 40051 | 404 | 会话不存在 |
| 40052 | 403 | 无权访问该会话 |
| 40053 | 400 | 订单不属于当前用户 |
| 40054 | 400 | 消息内容为空或超长 |
| 40055 | 400 | 图片 URL 非法 |
