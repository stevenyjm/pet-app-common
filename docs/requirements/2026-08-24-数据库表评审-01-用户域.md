## 开头：评审与决策参考的规范准则

> 以下为本次评审依据的规范准则速查，详细规则见规范母版。

### A. 必备字段

| 字段类别 | 字段名（强制） | 类型与约束 | 说明 |
|----------|---------------|------------|------|
| 主键 | `{实体}_code` | `VARCHAR(n) PRIMARY KEY`，禁止 `BIGINT AUTO_INCREMENT` | 业务主键 |
| 创建时间 | `create_time` | `DATETIME NOT NULL`（无 `DEFAULT CURRENT_TIMESTAMP`，后端推送） | 创建时间 |
| 最后修改时间 | `last_modified_time` | `DATETIME NOT NULL`（无 `DEFAULT`/`ON UPDATE`，后端推送） | 最后修改时间 |
| 逻辑删除标记 | `is_deleted` | `TINYINT NOT NULL DEFAULT 0` | 0-未删除，1-已删除 |

### B. 业务主键编码规则

| 实体 | 编码格式 | 字段类型建议 |
|------|----------|--------------|
| 用户 `user_code` | `U00000001`（前缀 `U` + 8 位数字） | `VARCHAR(16)` |
| 其他实体 | **在实际确定数据库表字段时，由用户询问决策** | 按需预留余量 |

### C. 其他已决策规则

| 规则 | 决策结果 |
|------|----------|
| 时间字段维护方式 | 后端主动推送（移除 DB 自动维护） |
| CONSTRAINT 约束 | 全量移除（引用完整性由后端校验） |
| 字段表源前缀 | 仅易混淆字段加前缀（`status`→`{entity}_status`、`name`→`{entity}_name`）；通用字段不加 |
| `is_deleted` 索引 | 移除单列索引；联合索引中 TINYINT 不作首列 |
| COMMENT | 表级与字段级 COMMENT 均不可省略；枚举字段标注取值映射 |
| TEXT/JSON 类型 | 避免使用；短文本用 VARCHAR(n)，数组用子表，结构化对象用扁平字段或子表；若触发分表须先向用户确认 |

## 表 1：user_account（用户主账号）

### 第一部分：当前数据表（旧表）

#### 字段介绍

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| user_id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| openid | VARCHAR(64) | NOT NULL, UNIQUE | 微信 openid |
| unionid | VARCHAR(64) | NULL | 微信 unionid |
| session_key | VARCHAR(128) | NOT NULL | 微信 session_key |
| status | TINYINT | NOT NULL, DEFAULT 1 | 1-正常 0-封禁 |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 最后更新时间 |
| last_login_time | DATETIME | NULL | 最后登录时间 |
| is_deleted | TINYINT | NOT NULL, DEFAULT 0 | 逻辑删除：0-未删除，1-已删除 |

#### 建表语句

```sql
CREATE TABLE IF NOT EXISTS `user_account` (
  `user_id` BIGINT NOT NULL AUTO_INCREMENT,
  `openid` VARCHAR(64) NOT NULL,
  `unionid` VARCHAR(64) DEFAULT NULL,
  `session_key` VARCHAR(128) NOT NULL,
  `status` TINYINT NOT NULL DEFAULT 1 COMMENT '1-正常 0-封禁',
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间（北京时间）',
  `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '最后更新时间（北京时间）',
  `last_login_time` DATETIME DEFAULT NULL,
  `is_deleted` TINYINT NOT NULL DEFAULT 0 COMMENT '逻辑删除：0-未删除，1-已逻辑删除',
  PRIMARY KEY (`user_id`),
  UNIQUE KEY `uk_openid` (`openid`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

#### 备注说明

- `user_id` 为逻辑主键（`BIGINT AUTO_INCREMENT`），违反 D1 业务主键规则
- `status` 字段名易混淆（联表查询时无法区分表源），违反 D2 字段表源前缀规则
- `created_at` / `updated_at` 命名不符 D3 时间字段命名（应为 `create_time` / `last_modified_time`）
- 时间字段使用 `DEFAULT CURRENT_TIMESTAMP` / `ON UPDATE CURRENT_TIMESTAMP`，违反 D3 维护方式规则（应后端推送）
- 无表级 `COMMENT`
- `openid` 等部分字段缺失 `COMMENT`

#### 建表语句

```sql
CREATE TABLE IF NOT EXISTS `user_profile` (
  `profile_id` BIGINT NOT NULL AUTO_INCREMENT COMMENT '主键',
  `user_id` BIGINT NOT NULL,
  `nickname` VARCHAR(64) DEFAULT NULL,
  `avatar_url` VARCHAR(255) DEFAULT NULL,
  `gender` TINYINT DEFAULT 0 COMMENT '0-未知 1-男 2-女',
  `phone` VARCHAR(20) DEFAULT NULL,
  `bio` VARCHAR(255) DEFAULT NULL,
  `email` VARCHAR(128) DEFAULT NULL,
  `invite_code` VARCHAR(16) NOT NULL,
  `inviter_user_id` BIGINT DEFAULT NULL COMMENT '邀请人 user_id',
  `invited_at` DATETIME DEFAULT NULL COMMENT '填写邀请码时间',
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间（北京时间）',
  `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '最后更新时间（北京时间）',
  `is_deleted` TINYINT NOT NULL DEFAULT 0 COMMENT '逻辑删除：0-未删除，1-已逻辑删除',
  PRIMARY KEY (`profile_id`),
  UNIQUE KEY `uk_user_id` (`user_id`),
  UNIQUE KEY `uk_invite_code` (`invite_code`),
  UNIQUE KEY `uk_email` (`email`),
  KEY `idx_inviter_user_id` (`inviter_user_id`),
  CONSTRAINT `fk_profile_user` FOREIGN KEY (`user_id`) REFERENCES `user_account` (`user_id`),
  CONSTRAINT `fk_profile_inviter` FOREIGN KEY (`inviter_user_id`) REFERENCES `user_account` (`user_id`)

```

#### 备注说明

- `profile_id` 为逻辑主键，违反 D1；`user_id` 已是业务外键引用，可考虑直接作为业务主键或改用 `user_code`
- `user_id` / `inviter_user_id` 为外键引用，需改为 `user_code` / `inviter_user_code`
- 2 处 `CONSTRAINT` 外键约束，违反 D5（应移除，引用完整性由后端校验）
- `created_at` / `updated_at` 命名与维护方式违反 D3
- `gender` 字段名易混淆（联表时可能与宠物性别混淆），建议加表源前缀
- 无表级 `COMMENT`
- `nickname` / `avatar_url` / `phone` / `bio` / `email` 等字段缺失 `COMMENT`
