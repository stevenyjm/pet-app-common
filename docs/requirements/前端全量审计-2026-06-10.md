## 5. 错误码与状态码专项审计

### 5.1 两套「码」的定义（避免混淆）

| 类型 | 位置 | 含义 | 示例 |
|------|------|------|------|
| **HTTP statusCode** | 响应头 | REST 层状态 | 200、401、404、422 |
| **业务 code** | 响应体 `code` | 后端 `AppError` 业务码 | 0=成功，40408=宠物不存在 |
| **订单 status** | 业务数据字段 | 订单生命周期 | 10/20/30/40/50/60 → pending/ship/… |
| **证件 cert_status** | 业务数据 TINYINT | 认证四态 | 0–3 → missing/pending/rejected/approved |
| **消息 category** | 业务数据 | 消息分类 Tab | 1–4 系统/订单/宠物/提醒 |
| **反馈 status** | 字符串 | 处理进度 | pending/processing/resolved/closed |
| **健康 status** | 前端 Mock | UI 指示 | ok/warn/none（非 API 码） |

以上域相互独立；审计中的「冲突」主要指 **业务 code** 的历史复用与文档不同步。
