## 1. 需求概述

在宠物页面的底部 Tab 栏中增加「回到今日」快捷入口，方便用户快速返回当前日期的记录。

| # | 需求摘要 | 状态 |
|---|----------|------|
| D1 | 在宠物页底部 Tab 栏增加「今日」按钮 | ✅ 已实现 |
| D2 | 点击「今日」按钮跳转到当前日期的日记记录 | ✅ 已实现 |
| D3 | 「今日」按钮在非今日日期时显示角标提示 | ✅ 已实现 |

---

## 2. 实现方案

### 2.1 Tab 栏结构

```text
宠物页 Tab 栏
├─ 日记（列表）
├─ 成长曲线
├─ 相册
└─ 今日（快捷入口）← 新增
```

### 2.2 交互逻辑

| 场景 | 行为 |
|------|------|
| 当前日期 | 「今日」按钮高亮 |
| 非当前日期 | 「今日」按钮显示角标（如：返回今日） |
| 点击「今日」 | 跳转至当前日期的日记详情 |
