## 2. 布局结构

```text
<view class="page-pet-info">
  ├─ 头部区域（渐变背景）
  │   ├─ 头像（圆形、边框、阴影）
  │   └─ 宠物名称 + 品种标签
  │
  ├─ 基本信息卡片
  │   ├─ 生日
  │   ├─ 年龄
  │   ├─ 性别
  │   ├─ 体重
  │   └─ 陪伴时长（新增）
  │
  ├─ 狗证信息卡片
  │   ├─ 证号
  │   ├─ 类型
  │   ├─ 领养/入籍日期（新增）
  │   ├─ 有效期
  │   └─ 认证状态徽章
  │
  └─ 操作按钮区
      ├─ 编辑资料
      ├─ 补充证件
      └─ 删除宠物
```

---

## 4. 实施要点

1. **头像区域**：使用 `clip-path: circle(80rpx)` 实现圆形头像；增加阴影效果
2. **基本信息卡片**：使用 `grid-template-columns: repeat(2, 1fr)` 双列布局
3. **狗证信息卡片**：认证状态使用 `el-tag` 组件，到期前 30 天显示警告色
4. **陪伴时长**：调用 `formatCompanionshipDisplay()` 格式化显示
5. **操作按钮**：统一使用主色背景，增加点击反馈动画
