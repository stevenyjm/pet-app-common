## 1. 需求背景

根据产品需求，需对宠物档案的"最近状态"区域进行扩展，新增以下功能：

| 需求项 | 说明 |
|--------|------|
| 宠物性别 | 新增性别字段，用于记录宠物的性别信息 |
| 最近身体状态 | 新增身体状态字段，用于记录宠物临时生理状态（如生病、发情期、孕期等） |
| 更新时间 | 为最近状态下的所有字段（心情、体重、排便健康、身体状态）添加最后更新时间 |

## 3. API 接口变更

### 3.1 创建宠物 `/pets`（POST）

#### 请求体新增字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `gender` | Integer | 否 | 性别：0-未知，1-雄性，2-雌性 |

#### 示例

```json
{
  "name": "豆豆",
  "breed": "柯基",
  "birthday": "2024-02-15",
  "gender": 1
}
```

### 3.2 更新宠物 `/pets/{petId}`（PUT）

#### 请求体新增字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `gender` | Integer | 否 | 性别：0-未知，1-雄性，2-雌性 |
| `latest_physical_state` | String | 否 | 最近身体状态描述（限6字） |

#### 示例

```json
{
  "name": "豆豆",
  "gender": 1,
  "latest_physical_state": "生病",
  "latest_mood": "低落",
  "latest_weight_kg": 18.3,
  "latest_stool_health": "正常"
}
```

### 3.3 获取宠物详情 `/pets/{petId}`（GET）

#### 响应体新增字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `gender` | Integer | 性别：0-未知，1-雄性，2-雌性 |
| `latest_physical_state` | String | 最近身体状态描述 |
| `latest_mood_update_time` | String | 最近心情更新时间（ISO 8601），服务端自动管理 |
| `latest_weight_update_time` | String | 最近体重更新时间（ISO 8601），服务端自动管理 |
| `latest_stool_update_time` | String | 最近排便健康更新时间（ISO 8601），服务端自动管理 |
| `latest_physical_state_update_time` | String | 最近身体状态更新时间（ISO 8601），服务端自动管理 |

#### 示例

```json
{
  "pet_id": 1,
  "name": "豆豆",
  "breed": "柯基",
  "gender": 1,
  "birthday": "2024-02-15",
  "latest_mood": "开心",
  "latest_mood_update_time": "2026-07-10T14:30:00",
  "latest_weight_kg": 18.3,
  "latest_weight_update_time": "2026-07-10T08:00:00",
  "latest_stool_health": "正常",
  "latest_stool_update_time": "2026-07-10T12:00:00",
  "latest_physical_state": "健康",
  "latest_physical_state_update_time": "2026-07-10T09:00:00"
}
```

### 3.4 获取宠物列表 `/pets`（GET）

#### 响应体列表项新增字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `gender` | Integer | 性别 |

## 5. 业务规则

### 5.1 性别字段规则

| 规则 | 说明 |
|------|------|
| 默认值 | 0（未知） |
| 可选值 | 0-未知，1-雄性，2-雌性 |
| 修改权限 | 组内成员均可修改 |

### 5.2 身体状态字段规则

| 规则 | 说明 |
|------|------|
| 字符限制 | 最多6个字符 |
| 输入方式 | 用户自由输入，不限制具体值 |
| 典型值 | 生病、发情期、孕期、康复中、健康、感冒、腹泻等 |
| 修改权限 | 组内成员均可修改 |

### 5.3 更新时间规则

| 规则 | 说明 |
|------|------|
| 触发时机 | 对应字段更新时自动设置为当前时间 |
| 时间精度 | 精确到秒 |
| 时间格式 | ISO 8601（如 `2026-07-10T14:30:00`） |
| 管理方式 | **服务端自动管理**，客户端请求体中不包含这些字段，响应体中返回 |

## 6. 迁移方案

### 6.1 数据库迁移

```sql
ALTER TABLE pet
  ADD COLUMN gender TINYINT DEFAULT 0 COMMENT '性别：0-未知，1-雄性，2-雌性' AFTER breed,
  ADD COLUMN latest_physical_state VARCHAR(6) COMMENT '最近身体状态描述（限6字）' AFTER latest_stool_health,
  ADD COLUMN latest_mood_update_time DATETIME COMMENT '最近心情更新时间' AFTER latest_mood,
  ADD COLUMN latest_weight_update_time DATETIME COMMENT '最近体重更新时间' AFTER latest_weight_kg,
  ADD COLUMN latest_stool_update_time DATETIME COMMENT '最近排便健康更新时间' AFTER latest_stool_health,
  ADD COLUMN latest_physical_state_update_time DATETIME COMMENT '最近身体状态更新时间' AFTER latest_physical_state;
```

### 6.2 数据初始化

| 字段 | 初始化规则 |
|------|------------|
| `gender` | 默认 0（未知） |
| `latest_physical_state` | 默认 NULL |
| 各更新时间字段 | 默认 NULL，首次更新时设置（服务端自动管理，客户端只读） |
