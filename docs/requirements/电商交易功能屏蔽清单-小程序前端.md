## 2. 功能限制清单

### 2.1 商品浏览功能

| 功能名称 | 限制内容 | 处理方式 |
|----------|----------|----------|
| **商品搜索** | 仅支持关键词搜索 | 不显示高级搜索选项 |
| **商品筛选** | 仅支持分类筛选 | 不显示价格区间、品牌等筛选 |
| **商品排序** | 仅支持默认排序 | 不显示价格、销量等排序选项 |

### 2.2 购物车功能

| 功能名称 | 限制内容 | 处理方式 |
|----------|----------|----------|
| **购物车数量** | 最多 50 件商品 | 超过 50 件时提示用户 |
| **购物车合并** | 不支持跨店铺合并 | 每个店铺单独结算 |

### 2.3 订单功能

| 功能名称 | 限制内容 | 处理方式 |
|----------|----------|----------|
| **订单数量** | 最多显示 100 条 | 超过 100 条时提示用户 |
| **订单详情** | 仅显示基本信息 | 不显示物流轨迹、评价等 |

## 3. 屏蔽方式说明

### 3.1 代码层面屏蔽

- **条件渲染**：使用 `v-if` 或 `wx:if` 条件渲染，根据配置控制功能显示/隐藏
- **路由拦截**：使用路由守卫，拦截被屏蔽功能的访问
- **组件隐藏**：通过 CSS 样式隐藏被屏蔽的组件

### 3.2 配置层面屏蔽

- **功能开关**：在后端配置功能开关，前端根据开关状态控制功能显示/隐藏
- **权限控制**：通过用户角色权限控制功能访问

## 4. 变更流程

1. **提出变更**：由产品或开发团队提出功能屏蔽/限制变更需求
2. **评估影响**：评估变更对用户体验和业务流程的影响
3. **更新清单**：修改本文档，记录变更内容
4. **代码实现**：在小程序前端代码中实现屏蔽/限制逻辑
5. **测试验证**：进行功能测试，确保屏蔽/限制生效
6. **记录变更**：在本文档末尾添加变更记录

---

## 5. 注意事项

1. **用户体验**：屏蔽功能时应考虑用户体验，避免出现空白页面或错误提示
2. **兼容性**：确保屏蔽逻辑在不同版本的微信客户端中都能正常工作
3. **可恢复性**：屏蔽的功能应保留恢复的可能性，便于后续业务扩展
4. **文档同步**：变更后及时更新本文档，确保团队成员了解最新状态
