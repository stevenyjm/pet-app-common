## 1. 问题描述

### 1.1 现状

当前扫码登录流程中，后端 `POST /auth/qrcode/create` 生成的二维码内容为小程序内部页面路径：

```
pages/login/qr-confirm?sceneId=qr_xxxxxxxx
```

这种自定义内容二维码**不被微信"扫一扫"识别**，导致用户在微信中扫描二维码后，显示为文本内容的空白页面（仅展示路径字符串）。

### 1.2 影响

- 用户无法通过微信"扫一扫"直接打开小程序确认页
- 扫码登录功能**仅支持**在小程序内部使用 `uni.scanCode()` 扫码
- 用户体验差，不符合微信生态习惯

### 1.3 预期效果

用户使用微信"扫一扫"扫描登录二维码后，应直接跳转到小程序的扫码确认页面（`pages/login/qr-confirm`），并携带 `sceneId` 参数。

## 2. 当前实现分析

### 2.1 后端接口

**POST `/auth/qrcode/create` 响应**（当前）：

```json
{
  "sceneId": "qr_xxxxxxxx",
  "expireAt": 1779719382540,
  "qrContent": "pages/login/qr-confirm?sceneId=qr_xxxxxxxx",
  "pollInterval": 2000,
  "qrImageUrl": "https://ispiexaisiki.sealoshzh.site/api/v1/auth/qrcode/qr_xxxxxxxx.png"
}
```

> `qrImageUrl` 由后端使用 `qrcode` 库动态生成 PNG，内容为 `qrContent` 字段值。

### 2.2 前端页面

**登录页**（[src/pages/login/login.vue](../pet-app/src/pages/login/login.vue)）：
- 调用 `createQrLoginSession()` 获取二维码信息
- 展示 `qrImageUrl` 图片
- 轮询 `pollQrLogin()` 等待确认

**扫码确认页**（[src/pages/login/qr-confirm.vue](../pet-app/src/pages/login/qr-confirm.vue)）：
- `onLoad(query)` 通过 `query.sceneId` 获取会话 ID
- 调用 `reportQrScanned()` 上报已扫码
- 点击「确认登录」按钮完成授权

### 2.3 扫码流程

```
用户A（待登录设备）                    用户B（扫码确认设备）
     ↓                                    ↓
 打开小程序登录页                     【问题点】必须打开同一小程序
 切换到"扫码登录"                     使用 uni.scanCode() 扫描
 勾选协议生成二维码                    跳转到 qr-confirm 页面
     ↓                                    ↓
 轮询等待确认（pollQrLogin）         点击"确认登录"按钮
     ↓                                    ↓
 检测到 confirmed 状态              返回
     ↓                                    ↓
 完成登录
```

## 3. 修改方案

### 3.1 后端修改

#### 3.1.1 调用微信小程序码 API

后端需要调用微信官方 API 生成小程序码，替换当前的自定义二维码。

**微信 API**：`POST https://api.weixin.qq.com/wxa/getwxacodeunlimit`

**请求参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `access_token` | string | 是 | 微信接口调用凭证 |
| `scene` | string | 是 | 最大 32 个可见字符，只支持数字，大小写英文以及部分特殊字符：!#$&'()*+,/:;=?@-._~ |
| `page` | string | 是 | 必须是已经发布的小程序存在的页面（否则报错），例如 pages/index/index |
| `width` | number | 否 | 二维码宽度，单位 px，最小 280px，最大 1280px，默认 430px |
| `auto_color` | boolean | 否 | 自动配置线条颜色，如果颜色依然是黑色，则说明不建议配置主色调 |
| `line_color` | object | 否 | 默认 {"r":"0","g":"0","b":"0"}，如需自定义颜色，建议使用深色 |
| `is_hyaline` | boolean | 否 | 是否需要透明底色，为 true 时，生成透明底色的小程序码 |

**实现要点**：

1. **获取 access_token**：
   - 使用 `WECHAT_APPID` 和 `WECHAT_SECRET` 调用 `https://api.weixin.qq.com/cgi-bin/token`
   - 缓存 access_token（有效期 7200 秒）

2. **生成小程序码**：
   - `scene` 参数传入 `sceneId`（如 `qr_xxxxxxxx`）
   - `page` 参数传入 `pages/login/qr-confirm`
   - 接收返回的二进制图片数据

3. **存储并返回图片 URL**：
   - 将小程序码图片保存到对象存储或本地
   - 返回可访问的图片 URL

#### 3.1.2 修改接口响应

**POST `/auth/qrcode/create` 响应**（修改后）：

```json
{
  "sceneId": "qr_xxxxxxxx",
  "expireAt": 1779719382540,
  "qrContent": "qr_xxxxxxxx",
  "pollInterval": 2000,
  "qrImageUrl": "https://ispiexaisiki.sealoshzh.site/api/v1/auth/qrcode/qr_xxxxxxxx.png",
  "isWxacode": true
}
```

**字段变更说明**：

| 字段 | 修改前 | 修改后 | 说明 |
|------|--------|--------|------|
| `qrContent` | 完整页面路径 | 仅 `sceneId` | 小程序码使用 `scene` 参数传递 |
| `isWxacode` | 无 | boolean | 标识是否为微信小程序码 |

#### 3.1.3 新增配置项

后端需要新增以下环境变量配置：

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `WECHAT_APPID` | 微信小程序 AppID | 已有 |
| `WECHAT_SECRET` | 微信小程序 AppSecret | 已有 |
| `WECHAT_TOKEN_EXPIRE` | access_token 缓存时间（秒） | 7000 |

### 3.2 前端修改

#### 3.2.1 修改扫码确认页参数获取

**文件**：[src/pages/login/qr-confirm.vue](../pet-app/src/pages/login/qr-confirm.vue)

**修改内容**：兼容两种参数传递方式

```javascript
onLoad(async (query) => {
  // 兼容两种方式：
  // 1. 小程序内扫码：query.sceneId（传统方式）
  // 2. 微信扫一扫小程序码：decodeURIComponent(query.scene)（新方式）
  const scene = query.sceneId || query.scene || ''
  sceneId.value = typeof scene === 'string' ? decodeURIComponent(scene) : ''
  
  if (!sceneId.value) {
    uni.showToast({ title: '无效的扫码会话', icon: 'none' })
    return
  }
  try {
    await reportQrScanned(sceneId.value)
  } catch (e) {
    uni.showToast({ title: getAuthErrorMessage(e, '会话无效或已过期'), icon: 'none' })
  }
})
```

#### 3.2.2 修改 QR 会话规范化

**文件**：[src/services/auth.js](../pet-app/src/services/auth.js)

**修改内容**：兼容 `qrContent` 字段的新格式

```javascript
function normalizeQrSession(raw = {}) {
  return {
    ...raw,
    sceneId: raw.sceneId ?? raw.scene_id ?? '',
    qrImageUrl: raw.qrImageUrl ?? raw.qr_image_url ?? '',
    pollInterval: raw.pollInterval ?? raw.poll_interval,
    qrContent: raw.qrContent ?? raw.qr_content ?? '',
    isWxacode: raw.isWxacode ?? false
  }
}
```

## 6. 注意事项

### 6.1 微信小程序码限制

1. **`scene` 参数限制**：最大 32 个可见字符，只支持数字、大小写英文及部分特殊字符
2. **`page` 参数限制**：必须是已经发布的小程序存在的页面，测试时需确保页面已发布
3. **调用频率限制**：微信 API 调用有频率限制，建议合理缓存

### 6.2 开发环境测试

1. **体验版测试**：在微信开发平台上传代码后，使用体验版测试
2. **正式版发布**：确认功能正常后，需发布正式版才能在生产环境使用
3. **测试号限制**：测试号可能无法生成小程序码，建议使用正式号测试

### 6.3 兼容性

1. **向后兼容**：前端需兼容两种参数传递方式（`sceneId` 和 `scene`）
2. **版本兼容**：后端返回的 `qrContent` 格式变化需保证不影响旧版前端

### 6.4 配置检查

确保后端已配置以下环境变量：

| 变量 | 值 |
|------|-----|
| `WECHAT_APPID` | `wx3aa2757710973eb2`（正式号） |
| `WECHAT_SECRET` | 对应正式号的 AppSecret |
| `APP_PUBLIC_URL` | 公网域名，用于生成图片 URL |
