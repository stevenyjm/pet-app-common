# 宠物标签页收起/展开方案

## 一、方案概述

### 1.1 目标

将宠物标签页的显示主体从「日记录」偏向「宠物」，通过收起/展开交互，让用户可以在「宠物列表视图」和「日记录视图」之间切换。

### 1.2 页面现状

当前页面结构（非空态）：

| 区域 | 组件 | 说明 |
|------|------|------|
| 顶部导航 | `TabNavBar` | 标题"宠物"+设置按钮 |
| 宠物选项区 | `pet-strip-wrap` | 横向滚动的宠物选择条 |
| 迷你宠物条 | `pet-mini-bar` | 收起宠物条后的精简显示 |
| 日期选项区 | `date-section` | 月份选择+周日期选择条 |
| 每日状态摘要 | `daily-summary` | 心情/体重/排便状态 |
| 日记录显示区 | `daily-records-section` | 餐食/运动记录列表 |
| 底部导航 | `BottomDock` | 四Tab底部导航栏 |

### 1.3 核心变更

1. **新增收起/展开按钮**：位于日期选项区上方，全行宽度
2. **日期+记录区整体收展**：将日期选项区、每日状态摘要、日记录显示区视作一个抽屉单元
3. **底部导航联动**：收起时隐藏 `BottomDock`，展开时显示
4. **宠物选项区布局切换**：收起状态下，宠物选项区从横向排列切换为竖向列表

---

## 二、页面状态定义

### 2.1 两种状态

| 状态 | 默认值 | 显示内容 | 宠物选项区布局 |
|------|--------|----------|----------------|
| **展开状态** | `expanded: true` | 日期选项区 + 每日状态摘要 + 日记录显示区 + 底部导航 | 横向滚动条（现有样式） |
| **收起状态** | `expanded: false` | 仅保留页面底部的展开按钮 | 竖向列表（新增样式） |

### 2.2 状态切换逻辑

```
展开状态 ──点击收起按钮/上滑手势──> 收起状态
    ↑                                       │
    └──────────点击展开按钮/下滑手势─────────┘
```

## 三、收起/展开动画方案

### 3.1 方案对比

| 方案 | 实现方式 | 视觉效果 | 优点 | 缺点 | 推荐度 |
|------|----------|----------|------|------|--------|
| **CSS Max-Height** | `max-height` + `overflow: hidden` + `transition` | 平滑的上下滑动 | 实现简单，自然回收空间 | 需要预估最大高度 | ★★★★★ |
| **CSS Transform** | `transform: translateY()` + `transition` | 整体位移滑动 | 性能最优（GPU加速） | 在flex布局中会留下空白，需配合其他手段 | ★★★★☆ |
| **CSS Clip-Path** | `clip-path` + `transition` | 渐进式裁剪收起 | 视觉独特 | 兼容性稍差，空间不回收 | ★★★☆☆ |

### 3.2 推荐方案：CSS Max-Height 动画

#### 3.2.1 实现原理

将「日期选项区 + 每日状态摘要 + 日记录显示区」包裹在一个容器内，通过 `max-height` 属性的过渡实现抽屉效果：

- **展开状态**：`max-height` 设置为一个足够大的值（如 `2000rpx`），允许内容完全显示
- **收起状态**：`max-height: 0`，配合 `overflow: hidden` 隐藏内容
- **过渡动画**：通过 `transition: max-height` 实现平滑的收起/展开效果

#### 3.2.2 动画参数设计

| 参数 | 值 | 说明 |
|------|-----|------|
| 动画时长 | `0.4s` | 收起/展开的总时长 |
| 缓动函数 | `cubic-bezier(0.4, 0, 0.2, 1)` | Material Design 标准缓动，开始快结束慢 |
| 透明度过渡 | `0.25s ease` | 稍短于高度动画，产生层次感 |
| 最大高度 | `2000rpx` | 预估内容最大高度 |

#### 3.2.3 布局结构

关键布局调整：

1. **页面主容器**：保持 `flex-direction: column`，宠物选项区和抽屉容器为同级兄弟
2. **宠物选项区**：收起状态下添加 `flex: 1`，使其填充剩余空间
3. **抽屉容器**：设置 `overflow: hidden` 和 `transition: max-height`
4. **底部导航**：通过 `v-show` 或 `opacity` 控制显示/隐藏

#### 3.2.4 底部导航联动

底部导航使用独立的过渡动画：

| 参数 | 值 |
|------|-----|
| 动画时长 | `0.3s` |
| 缓动函数 | `cubic-bezier(0.4, 0, 0.2, 1)` |
| 透明度过渡 | `0.2s ease` |

#### 3.2.5 展开按钮

收起状态下，页面底部保留一个展开按钮：

| 参数 | 值 |
|------|-----|
| 按钮高度 | `100rpx` |
| 动画时长 | `0.3s` |
| 出现时机 | 抽屉完全收起后 |

### 3.3 备选方案：Flex 空间回收 + Transform

当内容高度不确定且需要精确动画时，可采用混合方案：

1. 使用 `transform: translateY()` 实现视觉上的滑动效果
2. 使用 `max-height: 0` 配合 `overflow: hidden` 回收布局空间
3. 宠物选项区设置 `flex: 1`，在抽屉收起时自动填充空间

## 四、触摸手势交互

### 4.1 滑动手势设计

用户提到的"上下滑动的抽屉效果"，可通过触摸事件实现：

| 手势 | 触发条件 | 目标动作 |
|------|----------|----------|
| **上滑收起** | 在主内容区向上滑动距离 > 100rpx | 收起抽屉 |
| **下滑展开** | 在宠物列表区向下滑动距离 > 100rpx | 展开抽屉 |

### 4.2 手势实现要点

1. **触摸事件监听**：`touchstart`、`touchmove`、`touchend`
2. **滑动距离计算**：记录起始 Y 坐标，计算滑动差值
3. **阈值判断**：设置最小滑动距离（100rpx）和最小滑动速度
4. **动画触发**：滑动超过阈值后触发收起/展开动画
5. **冲突处理**：避免与列表滚动事件冲突

### 4.3 交互反馈

| 状态 | 反馈方式 |
|------|----------|
| 滑动中 | 根据滑动距离实时调整抽屉位置（弹性跟随） |
| 滑动不足阈值 | 回弹到原状态 |
| 滑动超过阈值 | 触发收起/展开动画 |

## 五、宠物选项区竖向布局设计

### 5.1 布局对比

| 状态 | 布局方式 | 每个宠物占用空间 | 显示信息 |
|------|----------|------------------|----------|
| 展开状态 | 横向滚动 | 约 160rpx（宽）× 80rpx（高） | 头像 + 名称 + 品种 |
| 收起状态 | 竖向列表 | 全屏宽度 × 140rpx（高） | 头像 + 名称 + 年龄 + 陪伴时长 + 体重 |

### 5.2 竖向列表结构

收起状态下，宠物选项区从横向滚动条切换为竖向列表：

- **左侧**：宠物头像（100rpx × 100rpx，圆角 50%）
- **中间**：宠物信息区（名称、品种、年龄、陪伴时长、体重）
- **右侧**：选中标记（当前宠物显示 ✓ 图标）

### 5.3 样式设计要点

| 元素 | 尺寸/样式 |
|------|-----------|
| 列表项高度 | `140rpx` |
| 头像大小 | `100rpx × 100rpx`，圆角 50% |
| 名称字号 | `32rpx`，font-weight 600 |
| 品种字号 | `24rpx`，颜色 $sub |
| 元信息字号 | `22rpx`，颜色 $muted |
| 选中态背景 | `$brand-light` 浅色背景 |
| 选中标记 | `36rpx`，颜色 $brand |

## 六、与现有机制的协调

### 6.1 现有机制分析

| 机制 | 当前作用 | 处理方式 |
|------|----------|----------|
| `petStripCollapsed` | 滚动时自动收起宠物选择条 | **保留**，但仅在展开状态下生效 |
| `pet-mini-bar` | 收起宠物条后的迷你显示 | **保留**，仅在展开状态下显示 |
| `tabPageDockLayout` | 底部导航栏布局计算 | **适配**，收起状态下隐藏底部导航 |

### 6.2 状态优先级

状态优先级从高到低：

1. **抽屉收起状态**（`drawerExpanded: false`）：覆盖所有展开状态的子机制
2. **宠物条收起状态**（`petStripCollapsed: true`）：仅在抽屉展开时生效
3. **正常状态**：所有元素完整显示

### 6.3 `tabPageDockLayout` 适配

收起状态下，底部导航隐藏：

- `scroll-bottom-spacer` 的高度计算需考虑底部导航是否可见
- 收起状态下 spacer 高度设为 0
- 展开状态下保持原有计算逻辑

## 七、交互流程

### 7.1 收起流程

```
用户点击收起按钮 / 上滑手势
    ↓
设置 drawerExpanded = false
    ↓
触发动画序列：
  1. 抽屉容器 max-height → 0，opacity → 0（约 400ms）
  2. 宠物选项区切换为竖向列表（过渡动画）
  3. 底部导航 opacity → 0，transform → translateY(100%)（约 300ms）
  4. 底部展开按钮渐入（约 300ms）
    ↓
动画完成，页面进入收起状态
```

### 7.2 展开流程

```
用户点击展开按钮 / 下滑手势
    ↓
设置 drawerExpanded = true
    ↓
触发动画序列：
  1. 底部展开按钮渐出（约 300ms）
  2. 宠物选项区切换为横向滚动条（过渡动画）
  3. 抽屉容器 max-height → 2000rpx，opacity → 1（约 400ms）
  4. 底部导航 opacity → 1，transform → translateY(0)（约 300ms）
    ↓
动画完成
    ↓
自动加载当前宠物的日记录数据
```

### 7.3 宠物选择交互

| 状态 | 选择宠物后的行为 |
|------|------------------|
| 展开状态 | 切换当前宠物，重新加载日记录（现有逻辑） |
| 收起状态 | 切换当前宠物，**不自动展开**，仅更新列表选中态 |

## 八、技术实现要点

### 8.1 状态管理

需新增状态变量：

- `drawerExpanded`: Boolean，控制抽屉展开/收起
- `touchStartY`: Number，记录触摸起始 Y 坐标
- `touchCurrentY`: Number，记录触摸当前 Y 坐标

### 8.2 宠物数据增强

收起状态下需要显示更多宠物信息：

| 字段 | 说明 | 计算方式 |
|------|------|----------|
| `ageText` | 年龄文本 | 根据生日计算，如"2岁3个月" |
| `daysWithMe` | 陪伴时长 | 根据建档日期计算，如"陪伴 365 天" |
| `weight` | 当前体重 | 取最近一次记录的体重 |

### 8.3 性能优化

1. **动画优化**：使用 CSS transition 而非 JS 动画，触发 GPU 加速
2. **惰性加载**：收起状态下停止日记录数据轮询
3. **事件拦截**：收起状态下 `pointer-events: none` 避免误触
4. **条件渲染**：使用 `v-show` 而非 `v-if` 保持组件实例，减少切换开销

## 九、注意事项

### 9.1 动画时序

- 抽屉收起动画应先于底部导航隐藏
- 展开按钮应在抽屉完全收起后才显示
- 宠物列表切换动画应与抽屉动画同步进行

### 9.2 数据一致性

- 收起状态下切换宠物，需确保展开后加载正确的日记录
- 建议在展开时强制刷新日记录数据

### 9.3 无障碍访问

- 收起/展开按钮需添加 `aria-label` 描述
- 状态切换时需发送屏幕阅读器通知

### 9.4 兼容性

- 小程序端需确保 `max-height` 和 `transition` 属性支持
- 触摸手势需处理不同设备的触摸事件差异
