## 1. 需求概述

将日常提醒功能从前端本地定时迁移至后端 Cron 任务，并扩展提醒类型。

| # | 需求摘要 | 状态 |
|---|----------|------|
| D1 | 后端实现提醒任务调度（Cron） | ✅ 已实现 |
| D2 | 支持多种提醒类型（喂食、饮水、洗澡、驱虫、疫苗） | ✅ 已实现 |
| D3 | 提醒消息推送至消息中心 | ✅ 已实现 |
| D4 | C 端小程序展示未读提醒角标 | ✅ 已实现 |
| D5 | 提醒设置页面（开启/关闭、时间调整） | 🟡 待开发 |

---

## 2. 提醒类型

| 类型 | 说明 | 默认频率 |
|------|------|----------|
| 喂食提醒 | 每日定时提醒喂食 | 每日 09:00 / 18:00 |
| 饮水提醒 | 每日定时提醒换水 | 每日 12:00 |
| 洗澡提醒 | 定期提醒洗澡 | 每 7 天 |
| 驱虫提醒 | 定期提醒驱虫 | 每 30 天 |
| 疫苗提醒 | 定期提醒疫苗 | 每 365 天 |

---

## 3. 后端实现

### 3.1 Cron 任务

```text
0 9,18 * * *    喂食提醒
0 12 * * *      饮水提醒
0 0 * * *       洗澡/驱虫/疫苗提醒（检查到期）
```

### 3.2 数据库表

| 表名 | 说明 |
|------|------|
| `reminders` | 提醒模板配置 |
| `reminder_logs` | 提醒发送记录 |
