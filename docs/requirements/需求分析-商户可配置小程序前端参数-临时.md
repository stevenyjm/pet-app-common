## 1. 需求概述

支持商户通过管理端配置小程序前端参数，包括主题颜色、底部导航图标、首页封面等，实现无需重新提交审核即可更新小程序外观。

| # | 需求摘要 | 状态 |
|---|----------|------|
| D1 | 后端提供 `GET /shop-config/public` 返回商户配置 | ✅ 已实现 |
| D2 | 小程序启动时拉取配置并缓存（24h） | ✅ 已实现 |
| D3 | 主题颜色配置（主色、辅色、文字色） | ✅ 已实现 |
| D4 | 底部导航图标动态配置（iconDefault、iconActive） | ✅ 已实现 |
| D5 | 首页封面图配置（banner） | ✅ 已实现 |
| D6 | 配置变更通知机制（WebSocket / 轮询） | 🟡 待开发 |

---

## 2. 配置结构

```json
{
  "version": 1,
  "theme": {
    "primaryColor": "#07C160",
    "secondaryColor": "#FF6B6B",
    "textColor": "#333333",
    "backgroundColor": "#F5F5F5"
  },
  "dock": {
    "background": "/static/dock/dock-bg.png",
    "slots": [...]
  },
  "home": {
    "banner": "https://example.com/banner.png"
  }
}
```

---

## 3. 实现架构

```text
小程序启动
    ↓
拉取 /shop-config/public
    ↓
缓存至本地 storage（TTL 24h）
    ↓
合并到全局配置
    ↓
应用主题样式
```

### 3.1 配置合并策略

| 优先级 | 来源 | 说明 |
|--------|------|------|
| 1 | 远程配置 | 商户通过管理端修改 |
| 2 | 本地默认 | `src/config/default.theme.json` |
| 3 | 硬编码 | 代码中的常量 |

### 3.2 主题应用

使用 CSS 变量实现主题切换：

```css
page {
  --primary-color: var(--remote-primary, #07C160);
  --secondary-color: var(--remote-secondary, #FF6B6B);
}
```
