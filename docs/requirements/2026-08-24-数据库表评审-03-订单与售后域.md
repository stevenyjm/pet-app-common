### C. 其他已决策规则

| 规则 | 决策结果 |
|------|----------|
| 时间字段维护方式 | 后端主动推送（移除 DB 自动维护） |
| CONSTRAINT 约束 | 全量移除（引用完整性由后端校验） |
| 字段表源前缀 | 仅易混淆字段加前缀（`status`→`{entity}_status`、`name`→`{entity}_name`）；通用字段不加；`order_status`/`refund_status`/`logistics_status` 等已有前缀字段保留 |
| `is_deleted` 索引 | 移除单列索引；联合索引中 TINYINT 不作首列 |
| COMMENT | 表级与字段级 COMMENT 均不可省略；枚举字段标注取值映射 |
| TEXT/JSON 类型 | 避免使用；短文本用 VARCHAR(n)，数组用子表，结构化对象用扁平字段或子表；若触发分表须先向用户确认 |
| TEXT/JSON 豁免候选 | 微信响应快照字段（如 `refund_record.extra_json`）结构由第三方决定，扁平化成本高，建议豁免 |

#### 建表语句

```sql
CREATE TABLE IF NOT EXISTS `order_main` (
  `order_id` BIGINT NOT NULL AUTO_INCREMENT,
  `user_id` BIGINT NOT NULL,
  `out_trade_no` VARCHAR(64) DEFAULT NULL,
  `total_amount` DECIMAL(10,2) NOT NULL,
  `pay_amount` DECIMAL(10,2) DEFAULT NULL,
  `subtotal` DECIMAL(10,2) DEFAULT NULL,
  `shipping_fee` DECIMAL(10,2) DEFAULT NULL,
  `coupon_discount` DECIMAL(10,2) NOT NULL DEFAULT 0,
  `buyer_message` VARCHAR(100) DEFAULT NULL,
  `delivery_method` VARCHAR(64) DEFAULT NULL,
  `cold_chain` TINYINT NOT NULL DEFAULT 0,
  `order_status` TINYINT NOT NULL COMMENT '10-待支付 20-待发货 30-待收货 40-已完成 50-已关闭 60-售后中',
  `address_snapshot` TEXT NOT NULL,
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间（北京时间）',
  `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '最后更新时间（北京时间）',
  `pay_time` DATETIME DEFAULT NULL,
  `expire_at` DATETIME DEFAULT NULL,
  `shipped_at` DATETIME DEFAULT NULL,
  `user_deleted_at` DATETIME DEFAULT NULL COMMENT 'C端用户逻辑删除时间（NULL=未删除）。与管理员 is_hidden 语义隔离，不复用',
  `is_deleted` TINYINT NOT NULL DEFAULT 0 COMMENT '逻辑删除：0-未删除，1-已逻辑删除',
  PRIMARY KEY (`order_id`),
  UNIQUE KEY `uk_out_trade_no` (`out_trade_no`),
  KEY `idx_user_status_time` (`user_id`, `order_status`, `created_at`),
  KEY `idx_user_deleted_time` (`user_id`, `user_deleted_at`, `created_at`),
  CONSTRAINT `fk_order_user` FOREIGN KEY (`user_id`) REFERENCES `user_account` (`user_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

#### 备注说明

- `order_id` 为逻辑主键（`BIGINT AUTO_INCREMENT`），违反 D1 业务主键规则
- `user_id` 外键引用需改为 `user_code`
- 1 处 `CONSTRAINT` 外键约束，违反 D5（应移除）
- `created_at` / `updated_at` 命名不符 D3（应为 `create_time` / `last_modified_time`）
- 时间字段使用 `DEFAULT CURRENT_TIMESTAMP` / `ON UPDATE CURRENT_TIMESTAMP`，违反 D3 维护方式（应后端推送）
- `address_snapshot` 为 `TEXT` 类型存储 JSON，违反 D7（应扁平化为字段或拆子表）
- `expire_at` / `shipped_at` / `user_deleted_at` 使用 `_at` 后缀，与 `_time` 后缀规范不一致（待评审）
- `order_status` 已有表源前缀，保留
- 多数字段缺失 `COMMENT`，无表级 `COMMENT`
