## 一、规范要点（合规判定标准）

每张表必须包含以下四类字段，命名/类型/约束均需符合：

| 字段类别 | 字段名（强制） | 类型与约束 |
|----------|---------------|------------|
| 主键 | `id` 或 `{实体}_id` | `BIGINT AUTO_INCREMENT PRIMARY KEY` 或业务主键 |
| 创建时间 | `created_at` | `DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP` |
| 最后更新时间 | `updated_at` | `DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP` |
| 逻辑删除标记 | `is_deleted` | `TINYINT NOT NULL DEFAULT 0`（0=未删除，1=已逻辑删除） |

**禁止替代命名**：`create_time` / `update_time` / `deleted` / `deleted_at` / `is_hidden`（用于软删语义）/ `is_active`（用于软删语义）。

**禁止替代语义**：`status` 字段表示业务状态枚举（订单状态、上下架等），不可参与逻辑删除判定。
