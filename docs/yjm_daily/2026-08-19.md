### 关键规范决策

1. **逻辑删除字段**：复用 `order_main.user_deleted_at`（C 端用户删除时间戳，NULL=未删除），与管理员侧 `is_deleted` 语义隔离，不复用
2. **状态门禁**：仅 `order_status ∈ {40, 50}`（已完成/已取消）可删，其余抛 42227
3. **幂等设计**：重复 DELETE 已删除订单返回 `already_deleted: true`，不抛错
4. **响应字段**：C 端 API 保持 snake_case（`order_id` / `user_deleted_at` / `already_deleted`）
5. **禁止物理 DELETE**：仅 `UPDATE order_main SET user_deleted_at = NOW()`，符合 §8 逻辑删除规范
6. **不提供用户自助恢复**：C 端删除后仅可通过管理端 `PATCH /admin/orders/:id/user-restore` 恢复（P1 优先级，本期不交付）
